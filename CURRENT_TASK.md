## Что произошло
После первого запуска пользователь сообщил «упало куча ошибок». В GitHub новых коммитов и свежего лога не оказалось. Точные сообщения консоли недоступны.
При статическом аудите обнаружено: вызовы `Invoke-RepoGit @('...')` передают массив позиционно, хотя функция ожидает один параметр `[string[]]$GitArgs`. Исправлено на `Invoke-RepoGit -GitArgs @('...')`; это только гипотеза о причине, а не подтверждённый root cause.

## Следующее действие (одно)
В существующей локальной папке `minimarket` выполнить:
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1 -Action preflight
```
**ВНИМАНИЕ:** если старый скрипт был скачан ранее, команда запустит старую версию. Перед её запуском необходимо отдельно безопасно синхронизировать Git:
```powershell
git status --short
git branch --show-current
git fetch origin
git switch development
git pull --ff-only origin development
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1 -Action preflight
```
При наличии локальных изменений, неожиданных веток или конфликтов остановиться, не выполнять reset/force; документация содержит порядок диагностики. Если SSH/HTTPS Git не авторизуется, пуш лога невозможен до решения проблемы доступа.

## Критерии завершения
- Команда проходит на Windows, `logs/LAST_RUN.log` появляется в GitHub и обновляется после каждого запуска.
- Нет утечек параметров `.env`; в логе читаются Source_SHA, действие, статус, код выхода.
- Новые коммиты GitHub подтверждают успешную запись; никакой гарантии публикации при отсутствии связи нет.
- При PASS перевести план к этапу 1 (финализация архитектуры/URL).
