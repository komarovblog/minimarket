## Текущий ОДИН шаг — создать отдельного пользователя MySQL через phpMyAdmin
1. Зайти в phpMyAdmin к серверу MySQL-8.0 под администратором; перейти **«Учётные записи пользователей» → «Добавить учётную запись пользователя»**.
2. Создать `minimarket_app` с хостом `localhost` и индивидуальным сильным паролем (не сообщать пароль в чат и не коммитить). Если пользователь с такими именем и хостом уже существует — не перезаписывать/не менять его пароль вслепую.
3. **Не создавать новую базу** из формы пользователя; **не выдавать глобальных привилегий**.
4. После создания в «Изменить привилегии» выдать этому пользователю права **только на существующую БД `minimarket`** (достаточные для установки Joomla и её SQL-миграций; допустимы все привилегии уровня именно этой БД, без глобальных).
5. Пользователь подтверждает завершение без пароля. Если вкладки прав недоступны — попросить скриншот формы без секретов, а не заставлять выполнять SQL.

Документация phpMyAdmin: https://docs.phpmyadmin.net/en/latest/privileges.html — создавать пользователя без глобальных прав, затем добавлять права на отдельную БД.
