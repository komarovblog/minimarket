# Локальные скрипты MiniMarket

Сейчас рабочих скриптов нет: сначала устанавливаем чистую Joomla 6 в `public_html` и подтверждаем её работу. Потом здесь появятся минимальные проверенные скрипты сборки Joomla ZIP-пакета собственного `com_minimarket` и тестирования. Скрипты не меняют ядро Joomla и не отправляют секреты в GitHub.
