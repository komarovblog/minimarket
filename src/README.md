# MiniMarket — состояние разработки (30.10.2026)

**Текущий продукт — один компонент `com_minimarket` со своими каталогом и заказами.** В `src/com_minimarket` теперь существуют настоящие исходники версии `0.1.0` (M0), а не только README. Команда `scripts/build.ps1` собирает установочный ZIP в `dist`. Пока ZIP не собран локально и установка в Joomla не подтверждена пользователем.

Этот репозиторий хранит только код расширения и документацию. Всё установленное Joomla Core и пользовательские данные находятся в `public_html` и MySQL, **не в Git**. Никакой торговли на Joomla Articles.
