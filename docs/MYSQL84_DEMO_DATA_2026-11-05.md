# MiniMarket — полный демонстрационный каталог под MySQL 8.4.8

**Дата:** 05.11.2026. **Источник схемы:** загруженный пользователем SQL-дамп новой Joomla 6 с MySQL 8.4.8, PHP 8.5.4, БД `minimarket`, префикс `nnop3_`. В дампе **31 таблица MiniMarket без записей каталога**. Дамп Joomla с конфиденциальными системными данными **не включён в GitHub**.

## Готовый файл

[`sample-data/minimarket_mysql84_nnop3_full_demo.sql`](../sample-data/minimarket_mysql84_nnop3_full_demo.sql) — **единый** SQL для импорта через phpMyAdmin в уже установленный компонент MiniMarket 0.5.50. Не нужно сначала импортировать старый `minimarket_toys_rich_import.sql` и затем отдельно бренды: здесь собраны все необходимые данные, справочники и назначения.

Включено: дерево категорий, опубликованные товары, SEO-поля, описания, характеристики и их значения, правила категорий, глобальные опции и значения, соответствующие конкретным товарам характеристики, матрица SKU с остатками, изображения галерей и SKU, связанные товары, пять вымышленных брендов, шесть коллекций, связи «товар–бренд» и «товар–коллекции». Несколько товаров входят в две коллекции.

**Изображения:** подготовленный путь `images/minimarket/sample-01.png` ... `images/minimarket/sample-10.png` — те десять файлов, которые уже есть в папке пользователя. В SQL распределены все десять путей между категориями, товарами, галереями, вариантами, брендами и коллекциями. Бинарные PNG файлы не копируются и не переименовываются.

## Установка и безопасность

1. Скопировать **полную резервную копию БД** перед импортом, даже если база свежая.
2. Проверить, что Joomla установлена, MiniMarket 0.5.50 установлен, MySQL 8.4, и таблицы `nnop3_minimarket_*` уже созданы. Префикс должен быть точно `nnop3_`, имя БД — `minimarket`.
3. Проверить расположение изображений **от корня публичного сайта**: `images/minimarket/sample-01.png` ... `sample-10.png`.
4. Открыть **phpMyAdmin → базу `minimarket` → Импорт**, выбрать только `minimarket_mysql84_nnop3_full_demo.sql`, UTF-8, импортировать.
5. После импорта файл выводит сводные числа по категориям, товарам, атрибутам, опциям, SKU, брендам, коллекциям, связям и изображениям.
6. Проверить MiniMarket: список категорий/товаров, карточки, бренд и несколько коллекций, значения характеристик, опции/SKU и медиа.

**Файл подходит только для ПУСТОГО каталога:** проверка через временную таблицу с `CHECK(existing_rows=0)` намеренно прекращает импорт, если существуют хотя бы категории, товары, атрибуты, опции, бренды либо коллекции. Файл не удаляет таблицы/данные. Никакие системные таблицы Joomla, пользователи, расширения или `configuration.php` не изменяются. Повторно запускать его поверх заполненного магазина не нужно.

**Данные являются демонстрационными:** не использовать для реальных продаж без проверки правдивости описаний, цен, наличия, возрастных ограничений и изображений.

## Код и версия

Это **отдельная итерация с данными**, исходный код MiniMarket не менялся и версия компонента остаётся **0.5.50**. Согласно [правилам поставки](DELIVERY_RULES.md), CI продолжает собирать установочный ZIP и кладёт новый SQL рядом с ним отдельным файлом. Создан также тест импорта на **MySQL 8.4** с реальными внешними ключами и проверкой назначения SKU, брендов и коллекций.
