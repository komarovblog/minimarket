# MiniMarket 0.5.47 — первый этап после приёмки

Дата: 04.11.2026. Только ветка `development`. Без SQL-миграции и без изменений матрицы SKU, медиа, каталога, старых товаров.

Реализовано:
1. На вкладке «Связи товаров» есть отдельная явная кнопка «Развернуть» / «Свернуть» с aria-expanded и RU/EN. Ссылка на название по-прежнему открывает саму связь, не переключает раскрытие. Состав и сохранение связей не изменены.
2. Вкладка «Импорт»: инструкция в Joomla с шагами «Скачать → заполнить → проверить → применить». Два шаблона (заполненный и пустой JSON) поставляются внутри установленного компонента и скачиваются из админки, через ACL и CSRF token, без GitHub.
3. Импорт остаётся безопасным JSON v1 с предпросмотром, повторной загрузкой без удаления отсутствующих записей. **Excel, CSV и экспорт в 0.5.47 ещё не реализованы**; нельзя обозначать их работающими кнопками.
4. Тесты сборки ZIP и сохранения предыдущих сущностей, тест локальной выдачи примеров.

Следующий шаг по прямому запросу пользователя: `0.5.48` — расширение импорта Excel/CSV и экспорта базовых сущностей через общий v1 контракт. Затем отдельная работа над полным round-trip SKU/вариантов/фото/видео и значений информационных характеристик. Не выдавать базовый v1 round-trip за полный перенос магазина.

Проверить после установки поверх 0.5.46: раскрытие связи отдельной кнопкой; переход по названию связи; скачивание JSON-примера из MiniMarket без GitHub; проверка/применение; отсутствие потерь в товаре. Файл `minimarket_toys_rich_import.sql` из `dist` не импортировать.
