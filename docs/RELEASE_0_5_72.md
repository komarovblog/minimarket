# MiniMarket 0.5.72 — профили магазина и аудит пользовательского дампа

Дата: 07.11.2026. Ветка `development`.

## Новый режим магазина

В Joomla MiniMarket → Настройки → Основное → Тип магазина
теперь можно выбрать `physical` (Физические товары, умолчание),
`digital` (Цифровые товары) либо `food_delivery` (Доставка еды).
Оба языка ru-RU и en-GB обновлены. Специальные сценарии для последних
двух режимов будут разработаны отдельно; выбор режима сам по себе не
создаёт таблицы заказов/доставок и не переписывает каталог.

Обновление компонента не требует ручной миграции SQL для этой настройки.
Автоматические тесты: PHP 8.4/8.5, MySQL 8.0/8.4, Windows ZIP.

## Исследование дампа 2026-11-07

Получен полный SQL export Joomla/MySQL 8.4, префикс `nnop3_`.
Он содержит конфиденциальные системные данные: исходный дамп не
коммитить и не публиковать. Только 33 таблицы MiniMarket относятся
к компоненту.

- 81 товар/комплект, 12 характеристик, 13 значений цветов.
- 770 scalar значений: 308 text presets и 462 number/boolean.
- 111 строк прежней таблицы множественного text preset выбора.
- 77 готовых связей с ID значений (цвета).
- 5 текстовых пресетных характеристик имеют в сумме 39 уникальных
  наименований вариантов; все 419 используемых вариантов совпадают
  с определениями и могут быть сопоставлены без предположений.
- Ожидаемые результаты при нормализации: 496 ID-связей значений и
  462 scalar number/boolean.

Результат — это **статическая проверка исходного дампа**. Подготовлен
черновик data-only миграции для испытания на копии БД; он
не является рабочим релизным SQL, не удаляет устаревшую схему, не
проверялся здесь на реальной MySQL 8.4. До завершения рефакторинга
сервисов и автоматических SQL/браузерных тестов в действующую БД
его не импортировать.

## Завершение cleanup

Сначала единая модель manual/preset с data-id значений, перевод
читателей/писателей, фильтров, импорта/экспорта и fresh schema;
затем транзакционная миграция preset/multi и проверка ссылок; лишь
затем удаление устаревших колонок/таблиц и E2E Joomla.
Версию 0.5.72 нельзя считать релизом legacy-cleanup.

## Артефакты

Windows `scripts/release-to-desktop.ps1` выдаёт компонент
`com_minimarket-0.5.72.zip`, отдельный
`mod_minimarket_toolbar-0.5.72.zip` и cumulative demo SQL 0.5.72.
Последний — повторяемые демоданные, не ручная миграция базы.
