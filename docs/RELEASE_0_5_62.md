# MiniMarket 0.5.62 — быстрый переход в Atum

Добавлен `mod_minimarket_quicklink`: встроенная в компонент и отдельно устанавливаемая кнопка с иконкой корзины и заголовком MiniMarket в административном `status`. Установка автоматически создаёт и публикует экземпляр модуля только при первом появлении; обновление сохраняет пользовательские параметры. Joomla core и шаблон Atum не изменяются. `core.manage` проверяется при отображении.

Настройки модуля: показать/скрыть, текст кнопки, иконка, текст, штатные позиция и порядок. Оба языка RU/EN. Скрипт сборки и `inspect-package.ps1` проверяют отдельный ZIP; `release-to-desktop.ps1` отдаёт оба ZIP + накопительный SQL новой версии 0.5.62.

Подробности: [QUICKLINK_0_5_62.md](QUICKLINK_0_5_62.md).

**Ограничение**: встроенная установка и рендер проверены с mock-API Joomla, PHP 8.4/8.5 и ZIP на Windows; сквозной browser smoke Joomla/Atum остаётся ручным шагом. При неполадках автоматического добавления доступен `mod_minimarket_quicklink-0.5.62.zip` для установки через Joomla Extension Manager. Накопительный SQL не требуется для работы кнопки.
