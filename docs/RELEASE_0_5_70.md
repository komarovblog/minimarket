# MiniMarket 0.5.70 — первая реализация динамических фильтров витрины

Дата: 07.11.2026. Ветка `development`.

## Что реализовано

- Опубликованные атрибуты и фактические значения товаров формируют фильтры категории.
- AND между характеристиками; OR между выбранными значениями одной характеристики.
- Для SKU фильтрация выполняется по настоящим активным сочетаниям, а не по независимым значениям цвета и размера.
- Чекбоксы, радиокнопки, выпадающие списки, текстовый поиск, числовые диапазоны и ползунки.
- При выборе отключаются несовместимые значения, пересчитывается количество подходящих товаров, меняется URL.
- Серверная фильтрация работает по параметрам `mmf` без JavaScript.
- Комбинации фильтров получают `noindex,follow` пока не реализованы отдельные SEO-страницы.
- База и текущие значения не изменены. Общий стиль админки 0.5.69 не менялся.

## Ограничения и продолжение

Этот релиз **не содержит завершённого удаления legacy-хранилища характеристик**.
Пробная очистка обнаружила необходимость миграции значений старых списков,
CSV/JSON-пресетов и таблицы множественного выбора. Поэтому рискованная
деструктивная миграция исключена из рабочего релиза до полноценного MySQL 8.4
round-trip и совместимости всех регрессионных тестов. Старые таблицы пока
остаются, данные защищены. Это не конечная каноническая схема.

Выполнение требования пользователя продолжается отдельным этапом: привести
все сервисы, свежую схему, импорт/экспорт и demo SQL к одной модели;
подготовить проверяемый SQL с сохранением всех значений, испытать на MySQL8.4,
только затем распространять его для живой БД.
