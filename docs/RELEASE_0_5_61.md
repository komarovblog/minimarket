# MiniMarket 0.5.61 — Фиды и виджетная главная

Дата: 06.11.2026, `development`.

Добавлены: редактор фидов с категориями, чекбоксами товаров и режимами автоматической/ручной выборки; новые независимые таблицы; безопасный публичный XML по ключу; начальный YML генератор с SKU и расчётной ценой комплектов; нативный dashboard Joomla с submenu/preset; переработанная главная с показателями и навигационными карточками. Приоритет: сохранить стиль Atum, не переписывать Joomla core.

**Ограничения:** это базовый YML, а не готовое официально сертифицированное соответствие Яндекс Маркет/VK/Авито/Google. Сейчас поддержаны варианты Yandex/VK YML; Avito, Google требуют отдельных адаптеров. Нет автоматической отправки, ещё нет корзины/заказов. Full JSON v2 не включает конфигурации новых фидов. Отдельная кнопка в верхней полосе может добавляться штатным модулем Joomla `customtop`, не устанавливается навязчиво автоматически.

Подробности, схема выбора, приёмочные сценарии и план: [FEEDS_0_5_61.md](FEEDS_0_5_61.md).

## Поставка

1. `git pull --ff-only origin development`.
2. `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\release-to-desktop.ps1`.
3. На рабочем столе `com_minimarket-0.5.61.zip` и `minimarket_mysql84_nnop3_update_0_5_61.sql`.
4. Установить ZIP поверх существующего MiniMarket; Joomla применит миграцию новой таблицы фидов. SQL — **не миграция**, а опциональное накопительное заполнение прежнего демонстрационного каталога. Бэкап перед импортом.

CI: PHP8.4/8.5, MySQL8.0/8.4, Windows artifact, модель выбора фидов, XML escaping, DOM тест редактора и MySQL feed CRUD. Проверка в реальном браузере Joomla ещё нужна.
