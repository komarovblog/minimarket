# MiniMarket 0.5.41 — единый редактор связей товаров

Дата: 04.11.2026.

## Что исправлено

1. В товаре можно раскрыть несколько связей; в разделе «Связи товаров» открывается тот же редактор состава. Каждая связь — отдельная раскрываемая строка.
2. Участники связи больше не имеют галочек — строка содержит кликабельное название товара и кнопку «Убрать товар». Название открывает административную карточку товара в новой вкладке. Название существующей связи в карточке товара ведёт в редактор связи в новой вкладке.
3. Создание связи из товара по умолчанию включает текущий товар; добавление остальных участников — поиск по названию/SKU или по категории с выдачей до 25 результатов.
4. «Убрать товар» удаляет только членство (строку в таблице minimarket_product_group_members), не саму связь, не других участников и не товары. Даже если созданную из товара связь покидает основатель или связь полностью опустеет, объект связи остаётся в общем списке.
5. «Удалить связь» — отдельное явное действие с подтверждением. Из товарной карточки удаление применяется после «Сохранить» с проверкой core.delete; из самостоятельного редактора — защищённая POST-задача group.deleteRelationship с CSRF и core.delete, вызовом GroupModel::delete и возвратом к списку связей. Товары и их SKU не удаляются.
6. Старый скрытый флаг enabled=false из редактора с чекбоксами понимается для совместимости, новые строки участников всегда включены. Нет дублирующих способов удаления участника.
7. Для этой версии миграция SQL не нужна — используется существующая таблица групп и участников. Версия Joomla компонента: 0.5.41.

## Автоматические проверки

- PHP 8.4/8.5: один редактор в двух формах, отсутствие чекбоксов, безопасные ссылки на товары в новой вкладке, различение удаления участника/группы, CSRF и права для полного удаления.
- MySQL 8: исходный товар может быть исключён из связи, остальные участники и сама связь останутся. Пустая связь остаётся в базе, когда последний товар исключён. SKU, цены и остатки продуктов не затрагиваются.
- Windows ZIP: проверка сборки и наличие двух файлов в dist.

## Проверка в установленной Joomla

1. Перед обновлением сохранить резервную копию БД minimarket. Установить ZIP версии 0.5.41; отдельный SQL с демонстрационными данными повторно НЕ импортировать.
2. Создать связь в карточке товара, добавить ещё два товара, сохранить. Открыть связь в разделе «Связи товаров» и убедиться, что состав идентичен.
3. Открыть название товара — карточка соответствующего товара откроется в новой вкладке.
4. В исходном товаре нажать «Убрать товар» на его собственной строке, сохранить. В карточке исходного товара связь исчезнет, в двух других и в общем разделе останется.
5. Убрать последнего участника. Пустая связь должна сохраниться в разделе. Только «Удалить связь» полностью удаляет группу после подтверждения.
6. Проверить удаление всей связи из товара и standalone группы, сохранение названий и состава, RU/EN, узкую ширину, Ctrl+F5.

Рабочая ветка только development; main и Joomla core не изменять. Для новой версии два отдельных файла: com_minimarket-0.5.41.zip и minimarket_toys_rich_import.sql.
