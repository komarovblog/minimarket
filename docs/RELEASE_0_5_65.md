# MiniMarket 0.5.65 — счётчики на всех плитках и тёмное оформление Atum

Дата: 06.11.2026. Ветка `development`, Joomla 6 / PHP 8.4–8.5.

## Исправления

1. **Тёмные плитки на главной MiniMarket.** Заменена белая подложка на тёмные цвета, сочетающиеся с Atum; текст и значки контрастные, при наведении плитка подсвечивается. Счётчики также оформлены тёмными аккуратными бейджами. CSS относится только к `.com-minimarket-dashboard`; боковое меню, другие компоненты и шаблон Joomla не изменяются.
2. **Везде добавлены реальные счётчики**: категории; товары (обычные); комплекты; бренды; коллекции; связи товаров; связи комплектов; характеристики; опции; фиды. Числа берутся из реальной БД и включают опубликованные/неопубликованные записи, как и штатные списки. Обычные товары и комплекты различаются по `product_type`; связи делятся по `product_groups.type`.
3. **«Импорт / Экспорт»** — вместо счётчика прочерк `—`. **«Заказы»** тоже имеют прочерк, так как подсистема заказов пока не реализована и отображать фиктивный ноль некорректно. Все остальные плитки показывают число (включая реальный ноль, если соответствующих записей пока нет).
4. Горизонтальные полноширинные полосы `Управление / Товары / Инструменты`, плитки по 25% строки и залитая кнопка «Открыть страницу каталога» сохранены.
5. Архитектура отдельной кнопки `mod_minimarket_toolbar` не меняется: это самостоятельный ZIP, который не включается в компонент.

## SQL и архивы

- `com_minimarket-0.5.65.zip` — новый компонент и обновление CSS/счётчиков;
- `mod_minimarket_toolbar-0.5.65.zip` — отдельный ZIP верхней кнопки Joomla (ставить повторно **необязательно**, если кнопка уже установлена в версии 0.5.64);
- `minimarket_mysql84_nnop3_update_0_5_65.sql` — накопительная безопасная версия демонстрационного SQL, изменения UI не требуют его повторного импорта.

Команда:

```powershell
Set-Location 'C:\OSPanel\home\minimarket.local'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\release-to-desktop.ps1
```

**Установка:** установить только `com_minimarket-0.5.65.zip` через Joomla → Система → Установить → Расширения. Компонент считает записи из существующих таблиц, новая миграция схемы для данной задачи не нужна. Для обновления верхнего модуля — отдельно ZIP `mod_minimarket_toolbar`.

## Тестирование

- `scripts/test-0-5-65-dashboard-counts.php` запускает настоящий Joomla HtmlView с макетом Factory/DB и сверяет **каждый SQL-запрос** для всех 10 счётчиков, проверяет отрисованные значения, прочерки у импорта и заказов, тёмные CSS-цвета и доступность focus/hover.
- `scripts/test-demo-sql-mysql84.php` дополнительно проверяет раздельные счётчики обычных и комплектных связей на настоящей тестовой MySQL 8.4; количество комплектных связей может быть ноль.
- Старые PHP-контракты горизонтальных полос, Windows-сборка двух отдельных ZIP, MySQL 8.0/8.4 и накопительный SQL остаются обязательны.

**Не проверено:** фактический внешний вид на конкретной локальной Joomla/Atum (браузерный E2E). Требуется установить ZIP и проверить визуально: белых плиток нет, у брендов и всех справочников числа, у импорта прочерк.
