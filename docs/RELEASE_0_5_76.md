# MiniMarket 0.5.76: системные и пользовательские фильтры

## Контракт настроек

У характеристики отдельные настройки: **подача** (не использовать, выпадающий
список, чекбоксы, числовой диапазон с полями, числовой диапазон с двойным ползунком),
**несколько значений** (да/нет) и **поиск по значениям** (да/нет).
«Да/нет» всегда одиночное; числовые диапазоны не поддерживают множественный
выбор; редактор и документ не участвуют в фильтре.

В настройках магазина появились системные фильтры цены, SKU и наличия, а
в параметрах категории — их переопределение (или наследование). Настройка
`filter_search` хранится отдельным полем в таблице характеристик.

## Загрузка

Глобальный и категорийный лимит карточек на страницу: 10/20/30/50.
Категория подгружает очередные страницы после пересечения следующей ссылки
с viewport; сервер сначала фильтрует/сортирует все доступные товары и затем
выдаёт требуемую порцию. Адреса фильтров и страниц доступны без JavaScript,
а пользовательские действия AJAX меняют только содержимое каталога.

Этот релиз не обещает постоянного времени ответа при миллионах SKU: ускорение
серверных запросов, индексов и ключевой пагинации — следующий этап после
фактического замера на базе заказчика. В браузере изображения грузятся лениво.

## Данные, установка и безопасность

Таблицы и связи не удаляются. Joomla выполняет `0.5.76.sql` при установке
компонента поверх `0.5.75`. Перед установкой — резервная копия БД.
Ручной import clean SQL, cumulative SQL и Joomla «Исправить» не нужны.
Опциональный SQL в релизе дополняет старые демогалереи, не очищая товары.
Компонент, отдельный модуль и дополнительный SQL подготавливаются
`scripts/release-to-desktop.ps1`.

Форма характеристик исправлена: `$source` вычисляется до первого использования.
Кнопки выбора «Все значения» отображают понятный текст.
