# MiniMarket 0.5.66 — нативные панели Atum

Дата: 06.11.2026. Ветка: `development`. Joomla 6; PHP 8.4/8.5.

## Изменения

- На главной MiniMarket три независимые панели «Управление / Магазин / Инструменты» оформлены как штатные виджеты Joomla: с отдельной строкой заголовка, рамкой, плитками без вертикальных меню.
- Ширина ограничена `max-width: 1120px`, а начиная с ширины окна 1200px панели отображаются в **две колонки равной ширины** — каждая сравнима со штатным модулем Joomla. На меньших экранах одна колонка. Плитки при широком экране — по 3 внутри панели, на средних 2, на узких 1; прежняя требуемая четверть всей ширины заменена актуальным требованием пользователя о размере штатной панели.
- Фон панели `#1c2a39`, плитки `#283a4e`, hover `#354d64`: приглушённый сине-графитовый вместо почти чёрного. Контрастные значки/счётчики, заметный focus, режим reduced-motion.
- Переименован только **заголовок раздела** «Товары» в «Магазин» (EN `Store`); каталог товаров по-прежнему называется «Товары». Заголовок «Магазин» имеет штатный Joomla `icon-cart`.
- «Комплекты» получают отдельную inline SVG-иконку из нескольких коробок, не зависящую от возможного отсутствия класса `icon-box` в шрифте Atum.
- Текущие 10 SQL-счётчиков, прочерки «Заказы» и «Импорт / Экспорт», 11 действующих переходов, отдельный модуль `mod_minimarket_toolbar` и кнопка каталога сохранены. Ядро Joomla не менялось.

## Поставка

- `com_minimarket-0.5.66.zip`;
- `mod_minimarket_toolbar-0.5.66.zip` — независимый модуль; переустановка не обязательна, так как логика не изменилась;
- `minimarket_mysql84_nnop3_update_0_5_66.sql` — побайтная копия безопасного накопительного демо SQL предыдущей версии. **Повторно импортировать для этих UI-изменений не нужно**. Миграции БД нет.

На Windows: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\OSPanel\home\minimarket.local\scripts\release-to-desktop.ps1"`. Затем установите ZIP компонента через Joomla → Система → Установить расширения.

## Проверки и ограничения

Автотест `scripts/test-0-5-66-dashboard-native.php` проверяет адаптивную ширину панелей, цвет, заголовки, отдельную SVG-иконку, RU/EN и отсутствие старого меню. Обновлены регрессии `test-0-5-64-dashboard.php`, `test-0-5-65-dashboard-counts.php` и Windows список артефактов.

Живой браузерный smoke в конкретной установленной Joomla/Atum **не выполнялся**: после установки убедиться, что 3 панели соответствуют ширине штатных Joomla dashboard-модулей, SVG комплектов виден, счётчики и ссылки работают.
