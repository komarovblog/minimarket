# MiniMarket 0.5.98 — согласованные настройки и продуктовая страница

**База:** 0.5.97, ветка `development`. **Не изменять:** core Joomla, Blank, main, существующие URL, SKU и другие сущности, реальные данные заказов и отзывов. Новых таблиц и SQL-миграций **нет**.

## Шесть изменений
1. В checkout «Описание шага» у покупателя, выбора доставки и выбора оплаты — штатное Joomla поле `editor`, `filter=safehtml`. На витрине HTML дополнительно пропускается через Joomla `InputFilter` с режимом HTML. Настройки не ломают ранее сохранённый обычный текст.
2. Надпись для режима `checkout_auth_mode=email` теперь «Обязательное подтверждение», без названия метода. Сохранено прежнее значение параметра для обновления. Пока email/SMS провайдер в процессе оформления не интегрирован, проверка fail-closed сохраняется: включение настройки **не создаёт** работающий SMS-код.
3. Вкладка «Отображение»: отдельный синий информер «Карточка товара», два шаблона `full`/`tabs` и 5 селектов видимости. Похожесть — по опубликованным доступным товарам текущей категории (кроме самого товара). «С этим покупают» — совместные позиции только из `confirmed`/`completed` заказов, исключая удалённые заказы и товары, недоступные на витрине; нет достаточных данных — блок отсутствует. Общие «Связи товаров» продолжают работать независимо.
4. Новая JS-навигация и нижняя панель покупки привязана к одной оригинальной форме заказа с действующими CSRF и SKU; дублирующая отправка не создана. JS выключен → все содержательные разделы доступны последовательно, стандартный POST работает.
5. Системные атрибуты Цена/Артикул/Наличие — только две последовательные настройки каждый, удалены три промежуточных названия. Значения системной фильтрации не изменены.
6. Удалена настройка «Подкатегорий на странице» из «Основных»: выводятся все **опубликованные** прямые подкатегории. Старая переменная params больше не влияет на вывод. «Команды интерфейса» передвинуты в самый конец вкладки «Общие».

## Проверки и ограничения
- `php scripts/test-0-5-98.php` — структурные контракты форм/потребителей/шаблонов, также обновлены исторические тесты 0.5.82/95/97 согласно новой спецификации.
- CI PHP 8.4/8.5, MySQL 8.0/8.4 и Windows ZIP. После запуска фиксировать их фактический статус отдельно.
- Обязателен Joomla 6 browser smoke: редактор RU/EN, обе темы, full/tabs, deep link на отзывы, навигация, отсечение неопубликованных товаров, история реальных заказов, SKU и disabled add-to-cart, прокрутка desktop/mobile, все опубликованные подкатегории, отсутствие дублирующих подписей.
- Для тестирования совместных покупок нужны настоящие подтверждённые/завершённые заказы с несколькими товарами; симуляция данных пользователя без согласия запрещена.
- Не импортировать cumulative demo SQL для этой версии: это необязательный отдельный каталог, **не миграция**.
