# MiniMarket 0.5.68 — компактные карточки и иконка импорта

Дата: 07.11.2026. Ветка `development`, Joomla 6 / Atum.

## Точечные правки по пользовательской приёмке 0.5.67

1. У плитки «Заказы» удалена подпись «Скоро». Иконка, название, прочерк вместо счётчика и отсутствие несуществующего перехода сохранены.
2. У всех плиток убрана фиксированная минимальная высота 6.3rem. Вертикальный внутренний отступ теперь .72rem сверху и снизу, расстояние от иконки/счётчика до названия .5rem — карточки стали компактнее, без искусственно пустого низа.
3. «Импорт / Экспорт»: вместо неподдерживаемого `icon-exchange-alt` отображается независимый SVG со стрелками импорта и экспорта. Ссылка и прочерк счётчика не менялись.

**Без других изменений:** три полноширинные секции в прежнем порядке, компоновка 1/2/4/6, цвета, шрифты, счётчики, названия разделов, верхняя кнопка и сама база данных неизменны.
