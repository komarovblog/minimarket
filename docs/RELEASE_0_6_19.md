# MiniMarket 0.6.19 — реальные управленческие отчёты

Вторая секция главной панели «Отчёты» содержит «Остатки», «Продажи», «Возвраты (отчёт)», «Показатели бизнеса». Все три новых отчёта доступны из меню слева, preset меню компонента и главной панели, с русскими/английскими названиями и стилем Joomla/Atum.

**Продажи:** только оплаченные завершённые заказы, детализация по товару/количеству/сумме до скидок и исторической себестоимости. Если одна из строк не имеет себестоимости, итоговую себестоимость товара не выдаём за ноль. Без ретроспективных изменений.

**Возвраты:** группировка обращений по причине и статусу, заявленное количество возвращаемых единиц; это не фактические возвратные выплаты, не движение склада и не выручка.

**Бизнес:** товары после скидки, начисленная клиентам доставка, историческая себестоимость товаров, фактическая сумма доставок, предварительная разница по товарам. Не чистая прибыль: не учитываются подтверждённые возвратные выплаты, эквайринг, налоги, реклама, другие издержки. Поэтому пустые/неизвестные затраты не подставляются нулями.

Даты UTC, диапазон не более пяти лет, права `core.admin` на каждую финансовую страницу. Нет новых аналитических таблиц и фиктивных показателей; миграция `0.6.19.sql` — `SELECT 1`. План-факт и маркетинговая атрибуция остаются отдельными задачами, пока нет подтверждённых исходных данных.

**Проверки:** `scripts/test-0-6-19-reports.php`, `test-0-6-19-reports-mysql84.php`, штатный PHP/MySQL/Windows CI. Joomla браузерный тест необходим после установки.
