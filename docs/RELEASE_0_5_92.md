# MiniMarket 0.5.92 — публичная карта сайта для магазина и статей Joomla

## Цель
Добавлена пятая разновидность фида — **XML Sitemap**. Это не YML и не отдельный плагин: используются существующие список фидов, редактирование, включение/выключение, ключ доступа, публикация и выбор товаров. Комплектов можно не включать; категории управляют автоматическим выбором товаров. Публикуемые материалы Joomla `com_content` добавляются автоматически.

## Защита
Выводятся товары только опубликованных категорий из `FeedSelection`; статьи — только `state=1`, категории `published=1`, уровень просмотра `access=1` («Public»), категория `com_content`, с учётом дат публикации. Ссылки строятся штатным маршрутизатором Joomla и проверяются на принадлежность домену и пути сайта. Лимит 5000 ссылок; XML экранирован и удаляет дубли. Фид по-прежнему доступен по длинному случайному ключу только после публикации.

## Проверка
`scripts/test-sitemap-feed.php`: генерация и экранирование XML, ссылки из подкаталога, запрет внешнего домена, даты, ограничения публичности. Добавлено в CI на PHP 8.4/8.5. После установки Joomla проверить настоящий публичный URL XML Sitemap, реальные SEF URL статей и товаров, неиндексацию закрытых статей, отключение и перепубликацию.

## Область и ограничения
SKU-экспорт в XLSX/CSV/JSON, конструктор сочетаний, per-category флаги опций и характеристик, расширенные системные фильтры и дополнительные поля чекаута — **следующие отдельные сквозные этапы, не объявляются готовыми**. Плагины не создавались, торговые сервисы и SQL-схема не менялись. `Blank` отложен.

## Точечная доработка после первого CI PASS

- XML sitemap исключает статьи, если любая вложенная категория Joomla ограничена или снята с публикации, даже если сама категория статьи опубликована. Проверка в `test-sitemap-feed.php`.
- При выборе Sitemap в редакторе отображается пояснение о товарах и материалах Joomla; для остальных провайдеров YML это не меняет настройки.
- В формах Характеристики/Опции четвёртое значение «Наследовать» переименовано в «По настройке магазина»; остальные три названия явно различают карточку товара и карточку товара в списке. Само наследование сохранено, без изменения поведения и ранее введённых значений.
