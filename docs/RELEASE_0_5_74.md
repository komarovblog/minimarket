# MiniMarket 0.5.74 — корзина физических товаров

**Область:** сайт MiniMarket, Joomla 6, PHP 8.4/8.5, без изменений ядра Joomla. Ветка development.

## Выполнено

- Корзина в сессии Joomla: добавление товара/комплекта, изменение количества и удаление.
- Точная идентичность позиции: `product_id + variant_id`. Для разных цветов/размеров SKU — отдельные строки корзины.
- Кнопка «В корзину» синхронизируется с выбранным SKU на витрине. При отсутствии остатка блокируется; сервер всегда проверяет независимо от JS.
- Сервер при каждой операции заново читает опубликованный товар, актуальную цену, SKU и наличие. Форма не может установить цену.
- Совокупный контроль остатков учитывает товары, SKU с общим складом и вложенные комплекты; общий лимит учитывает конкуренцию за одни компоненты. Поддержан выключенный глобально контроль остатков, но не неопубликованные товары.
- Страница `/cart`, доступная из каталога, категорий и карточки товара; русская и английская локализация; POST+CSRF+PRG; noindex и private/no-store.
- Нет миграции таблиц: `0.5.74.sql` — маркер версии для Joomla. Исправлен установочный housekeeping SQL, чтобы не возвращать старые ошибки проверки базы данных.
- Тесты `scripts/test-0-5-74-cart.php`.

## Ограничения этапа

Сессия не является заказом, цены и остатки не фиксируются, товары не резервируются и не списываются. Оформление, доставка, оплата, регистрация заказов и личный кабинет запланированы отдельно. Пользовательские покупки цифровых товаров и режим доставки еды не реализованы. Нужна ручная проверка на установленной Joomla (браузерный E2E здесь не запускался).

## Как обновить

1. Полная резервная копия БД и копия установленного компонента.
2. `git pull --ff-only origin development`.
3. `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\release-to-desktop.ps1`.
4. Установить на сайте `com_minimarket-0.5.74.zip` поверх старого компонента Joomla.
5. Не удалять таблицы и не импортировать clean/demo SQL: корзина хранится в сессии. Модуль toolbar автономен, переустановка не обязательна.
6. На сайте протестировать разные SKU, корзину, изменение количества, остатки, комплекты, запрет отсутствующего SKU, гостевой сеанс.
