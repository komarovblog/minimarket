# MiniMarket 0.5.22 — нативные категории, таблицы, варианты

**03.11.2026.** Улучшение интерфейса без миграции базы. Код в ветке `development`. Инструкция для проверки *установленной* Joomla 6; успешная CI не заменяет ручной smoke.

## Категории

1. Открыть MiniMarket → Категории, в том числе с многоуровневой вложенностью.
2. Убедиться, что все ветки сразу видны; **нет** кнопки сворачивания/раскрытия. Вложенные названия с тире и отступом, как Joomla Articles → Categories. Изображение-превью кликабельно.
3. Проверить чекбоксы, публикацию, Toolbar, SearchTools, сортировку, создание/редактирование, фильтр по статусу и поиск по вложенному названию. Отображение численности прямых товаров и по ветке сохранить.
4. В карточке категории → Характеристики проверить двухколоночную обычную Joomla-таблицу: название/код + компактный статус наследования, выпадающий режим. Проверить наследование, обязательность, исключение и сохранение.
5. В карточке характеристики → Категории убедиться в той же таблице и сохранить обратное назначение.

## Варианты

1. Создать или открыть обычный товар **без обязательных глобальных характеристик для вариантов**.
2. Во вкладке «Варианты» нажать `+` у «Параметры вариантов», ввести «Цвет». У «Значения» добавлять `+`: Красный, Синий. При необходимости `-` убрать значение и перетащить строки для порядка. Затем аналогично добавить второй параметр «Размер», значения S/M/L.
3. Нажать «Создать комбинации»: должна появиться обычная таблица с 6 сочетаниями и чекбоксами. Снять галочку с ненужного сочетания, добавить выбранные.
4. В таблице SKU заполнить/проверить артикул, цену, остаток, публикацию. Фото выбирается штатным Joomla Media, в поле нет суффикса `#joomlaImage://`. При отсутствии фото использовать общее фото товара.
5. Сохранить и повторно открыть: параметры, значения, их порядок, варианты и цены/остатки сохранились. При повторном создании комбинаций уже существующие SKU не дублируются.
6. На витрине: переключение меняет SKU, цену, остаток, фотографии без смены основного URL. Проверить `?variant=id`; 0 остаток — недоступно.
7. Для товара со **старыми** SKU (0.5.17–0.5.19) редактор сохраняет совместимый режим, не выполняет неявную миграцию или уничтожение старых SKU. Для простого товара цена/остаток остаются в старых полях до следующего этапа единой SKU-миграции.
8. Проверить RU/EN, тёмную тему Joomla, в том числе ширину и доступность нативной таблицы на широком и узком экране. Backup БД перед установкой ZIP.

## Границы

0.5.22 меняет **интерфейс**, а не структуру SKU или импорта. Не реализованы массовое табличное редактирование тысяч SKU, полноценная корзина, комплекты, фиды и автоматическое объединение старых вариантов. Глобальные характеристики остаются для описаний/фасетов, но не обязательны для создания локального SKU. В будущем новые разделы обязаны соблюдать [общий UI-стандарт](ADMIN_UI_STANDARD.md).
