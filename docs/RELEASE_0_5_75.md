# MiniMarket 0.5.75 — витрина, фильтры, корзина и демоданные

Релиз для Joomla 6 / PHP 8.4–8.5 / MySQL 8.4, ветка `development`.

## Каталог и SEO

- При включённом контроле остатков позиции без доступных единиц скрыты из главного каталога и категорий. Счётчик и пагинация учитывают только доступные записи.
- Для товаров с SKU наличие определяется активными сочетаниями и режимом общего/раздельного остатка. Комплекты проверяются по составу и вложенным комплектам.
- Прямые ссылки на опубликованные товары без остатков сохранены, включая канонические SEO-адреса; на странице отображается статус «Нет в наличии» и до шести доступных аналогов.
- При отключённом глобальном учёте остатков каталог не ограничивается остатками.

## Фильтрация и сортировка

- Цена добавлена в фильтр как диапазон с двумя ползунками.
- Выбор из списка раскрывается как чеклист с живым поиском; поддерживается одиночный или множественный выбор по настройке характеристики.
- Значения и группы выводят динамическое число подходящих товаров. Между характеристиками И, внутри одной — ИЛИ; учтены реальные SKU.
- Сортировка над товарами: новые, название, цена по возрастанию, цена по убыванию. Работает на странице категории и в общем каталоге; сохраняет фильтры в URL.
- Метка скидки больше не выводит символ минуса перед суммой.

## Корзина

- Изменение количества сохраняется автоматически после изменения числа / с задержкой после ввода.
- Удалена видимая кнопка «Обновить» для каждой позиции; без JavaScript доступна кнопка внутри `noscript`.
- Сервер вычисляет максимальное количество с учётом всех строк корзины и вложенных комплектов и принудительно уменьшает превышение. Отключение учёта остатков учитывается.
- Заказ, резервы и списания не создаются: это отдельная будущая очередь.

## Демоданные

- `sample-data/minimarket_demo_gallery_filters_0_5_75.sql` — дополнительный, повторяемый SQL для существующего каталога: исправляет исторические ссылки на отсутствующие `sample-11…20`, заполняет галереи всех демонстрационных игрушек и комплектов и создаёт 5 характеристик с разными режимами фильтра.
- Используются **только уже имеющиеся** `images/minimarket/sample-01.png` … `sample-10.png`; изображения не генерируются.
- SQL не очищает каталог и не изменяет схему. Вручную импортировать только после полного резервного копирования БД, если нужны расширенные демоданные.

## Установка

1. Резервная копия БД `minimarket` и установленного сайта.
2. Из `C:\OSPanel\home\minimarket.local` запустить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\release-to-desktop.ps1`.
3. Установить `com_minimarket-0.5.75.zip` поверх установленного компонента.
4. **Не импортировать** cumulative/clean SQL для обновления существующего магазина.
5. Для демогалерей и тестов фильтров импортировать *только* `minimarket_demo_gallery_filters_0_5_75.sql` из Desktop (опционально). Модуль поставляется отдельно и для изменения витрины не обязателен.
6. Проверить список, прямой URL OOS товара, корзину, SKU, комплекты, поиск в фильтре, price-slider и сортировку в браузере.

CI проверяет PHP, JavaScript, MySQL и ZIP, но реальная Joomla-браузерная приёмка проводится после установки.
