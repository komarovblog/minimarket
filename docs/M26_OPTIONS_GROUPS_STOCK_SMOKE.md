# MiniMarket 0.5.26 — опции, склад, связанные товары

**03.11.2026.** Утверждённая [архитектура V4](PRODUCT_ARCHITECTURE_V4_ATTRIBUTES_OPTIONS_LINKED_PRODUCTS.md). PHP/ZIP/MySQL CI не заменяет ручную проверку установленной Joomla 6. До установки на пользовательскую БД — резервная копия.

## Проверяем новую модель

1. Открыть MiniMarket → Товары → новый товар. Проверить две независимые вкладки: «Характеристики» (информация) и **«Опции заказа»** (выбор влияет на заказ). Опции создаются через штатные Joomla `+`, не требуют назначения атрибута категории.
2. В «Основное» по умолчанию выбрать **«Общий остаток товара»**; задать общий остаток 25. Создать опции «Цвет» (синий, красный), «Размер» (S,M) и **четыре уникальных SKU**. Вкладка не должна показывать поля индивидуальных остатков SKU — они сохраняются в БД и скрыты визуально. При выборе любого SKU на сайте наличие — из общего остатка 25.
3. Изменить учёт на **«Отдельно для каждого сочетания»**, сохранить и открыть снова. Поля остатков SKU доступны; задать синий/S=5, синий/M=10, красный/S=0, красный/M=7. На витрине смена выбранной комбинации меняет соответствующий остаток, URL один. При возврате к общему режиму старые числа сочетаний не теряются, снова доступны после обратного переключения.
4. В «Связанные товары» на новом красном товаре создать группу «Футболка Classic», сохранить. Создать/открыть самостоятельную синюю футболку с отдельным SKU, галереей, описанием, SEO и URL. В её вкладке выбрать уже созданную группу. На сайте у каждой футболки собственный URL; выводятся ссылки на другие опубликованные товары группы.
5. Убрать из группы один товар через «Без группы», проверить исчезновение перелинковки. Отключённый товар не должен появляться в ссылках другого. Неправильный ID группы, создание новой и выбор существующей одновременно — ошибка без частичного сохранения.
6. Открыть старый товар с SKU из 0.5.17–0.5.25. Миграция 0.5.26 не должна менять его SKU, URL, цены или числа остатков. Режим остатков выставлен «Отдельно для каждого сочетания»; старый механизм совместим.
7. Проверить RU/EN, мобильную ширину, тёмную тему, корректные штатные поля Joomla, сохранение и применённые значения. Тестировать с реальными изменениями, но до этого резервная копия.

## Что не следует считать готовым

0.5.26 — первая совместимая реализация модели. Нет пока отдельного **глобального справочника** опций с назначением категориям (используются уже существующие локальные опции товара), полноценного мастера импорта/экспорта, SKU-ориентированного фильтра каталога, корзины и резервирования остатков или массового редактора групп. Текущая схема `products.sku/price/stock` остаётся ради совместимости до отдельной проверенной миграции SKU C. Ручная Joomla-приёмка ещё не подтверждена.
