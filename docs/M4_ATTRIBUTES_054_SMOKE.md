# MiniMarket 0.5.4 — характеристики и значения

**01.11.2026. Состояние:** исходники опубликованы, автоматические проверки PHP 8.4/8.5, MySQL 8 и Windows ZIP пройдены на предшествующем коммите; установка и работа в реальной Joomla ещё не проверялись.

## Возможности

В MiniMarket появляется отдельный раздел «Характеристики» с полями: название, уникальный латинский код, тип, флаги «Различает варианты» и «Использовать в фильтрах», порядок, публикация.

Типы:
- **Список** — значения из отдельного справочника с собственными ID, кодами, порядком и публикацией. Только список может различать варианты товара.
- **Текст, Число, Да/Нет** — будущие типизированные общие свойства товара; ввод их значений в самом товаре ещё не реализован.

Например, «Цвет» (color): «Красный» (red), «Жёлтый» (yellow); «Размер» (size): S (s), M (m), L (l).

SQL обновление 0.5.4 создаёт только таблицы #__minimarket_attributes и #__minimarket_attribute_values; не меняет существующие товары, SKU, цены, остатки, URL, изображения и галереи. Историческая миграция 0.4.0.sql из старой feature-ветки в ZIP не включена.

## Обновление Joomla

1. **Сначала сохранить резервную копию БД Joomla.** Не удалять компонент и не запускать ручной SQL.
2. В CMD, в каталоге C:\OSPanel\home\minimarket.local:

```bat
git pull --ff-only origin development
"C:\OSPanel\modules\PHP-8.5\php.exe" scripts\test-attributes.php
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\inspect-package.ps1
```

3. Ожидаемый результат: **PACKAGE_OK: 0.5.4 (com_minimarket-0.5.4.zip)**.
4. Joomla → Система → Установка → Расширения: установить только dist\com_minimarket-0.5.4.zip поверх существующего компонента.

## Одна проверка

1. MiniMarket → Характеристики → Создать: **Цвет**, код **color**, тип **Список**, «Различает варианты» — Да, «Использовать в фильтрах» — Да, Опубликовано. Сохранить.
2. В списке характеристик перейти «Редактировать значения»: **Красный/red**, **Жёлтый/yellow**. Сохранить и открыть заново.
3. Создать характеристику **Размер/size**, список, флаг «Различает варианты» — Да; добавить значения **S/s, M/m, L/l**.
4. Проверить: повторный код **red** в «Цвет» должен отклоняться. У характеристики типа «Число» нельзя включить «Различает варианты».
5. Открыть существующий товар TEST-001: его ID, URL, SKU, цена, остаток, категория, изображения и статус должны остаться прежними.

**Внимание:** в этой версии нельзя назначить свойство товару или создать SKU-комбинацию «красный + M». Флаги вариантов и фильтров — подготовка схемы, а не уже работающие варианты и фильтры. Следующий этап — реальные комбинации SKU.
