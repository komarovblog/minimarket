# MiniMarket 0.5.63 — самостоятельная кнопка и упрощённая главная

Дата: 06.11.2026. Ветка `development`. Основная задача: кнопка MiniMarket **отдельным модулем**, а не внутри сборки компонента.

## Установка и структура

- `com_minimarket-0.5.63.zip` — только компонент MiniMarket; **не включает** `mod_minimarket_quicklink`, не вызывает его установку, не управляет публикацией или положением модуля.
- `mod_minimarket_quicklink-0.5.63.zip` — **самостоятельный администраторский модуль**; устанавливается отдельно через Joomla → Система → Установить → Расширения.
- `minimarket_mysql84_nnop3_update_0_5_63.sql` — версионированный накопительный демокаталог, обновление не нужно для этого UI.
- Компонент по-прежнему регистрирует собственный штатный Joomla-dashboard и боковое меню. Ядро Joomla и Atum не меняются.
- Старый `mod_minimarket_quicklink`, автоматически поставленный версией 0.5.62, **не удаляется** при обновлении компонента: для нового вида и перемещения кнопки установите отдельный ZIP модуля поверх существующего.

## Кнопка в шапке Atum

В качестве образца взяты штатные файлы Joomla 6.2:
- `administrator/templates/atum/html/layouts/status.php`
- `administrator/modules/mod_frontend/tmpl/default.php`
- `administrator/modules/mod_version/tmpl/default.php`

Кнопка теперь использует их классы `header-item-content`, `header-item-icon`, `header-item-text` без Bootstrap-классов `btn`. Поэтому иконка корзины и надпись в точности используют штатные стили шапки Atum, включая адаптивную группу `header-more`.

Модуль устанавливается в позицию `status`. Собственный Joomla installer `mod_minimarket_quicklinkInstallerScript` при установке публикует экземпляр модуля, назначает его всем административным страницам, задаёт уровень доступа Special и порядок **непосредственно слева от `mod_version`**. Порядок определяется штатным полем `#__modules.ordering` — без JS, CSS `order`, DOM-перестановок и правок ядра.

При повторной установке/обновлении модуль сохраняет отключение, изменение позиции и текста, если пользователь их изменил. Только если модуль остаётся в позиции `status`, установщик выравнивает его порядок перед версией Joomla. Отсутствующий `mod_version` не вызывает ошибок; но точное размещение «слева от версии» в таком случае неприменимо.

## Главная страница компонента

Штатный `view=dashboard` содержит **три одинаковых блока по четверти строки** на широком экране (`col-xl-3`), на планшете 2 в ряд (`col-md-6`), на телефоне один в ряд (`col-12`). Четвёртая четверть остаётся свободной под новые функции.

- **Заказы** — первый блок, только заголовок с корзиной и текст о планируемом запуске. Не изображаем неработающие кнопки или числа заказов. Позднее можно добавить доставку и управление заказами.
- **Магазин** — категории, товары, комплекты, бренды, коллекции, связи товаров и комплектов, характеристики, опции. Количество записей выводится спокойными бейджами у категорий/товаров/комплектов.
- **Инструменты** — импорт и экспорт, фиды. Заголовок с иконкой инструмента.

В заголовках разделов **иконка слева от названия**, используем штатные Joomla icon-классы и карточки Bootstrap. Удалена лишняя полоса отдельных статистических виджетов над разделами. Кнопка **«Открыть страницу каталога» теперь залитая** `btn btn-primary` с иконкой слева, открывает витрину в новой вкладке.

## Регрессии и проверка

- PHP 8.4/8.5: тесты рендера кнопки, прав доступа, параметров, перевода и XSS; mock installer standalone module: первое включение, место перед `mod_version`, сохранение публикации/другой позиции на повторном обновлении.
- PHP-контракт нативного интерфейса: три четвертных блока, правильное распределение, залитая кнопка.
- Windows: `build.ps1` собирает два независимых ZIP, `inspect-package.ps1` убеждается, что в ZIP компонента **нет** модуля, а ZIP модуля имеет свой манифест и `script.php`.
- MySQL8.0/8.4: старые данные и новый накопительный SQL проходят тесты, схема БД для данной правки не меняется.
- **Реальная установка и внешний вид Atum требуют просмотра на локальной Joomla**; браузерный E2E с живой Joomla не запускался.

## Порядок приёмки пользователем

1. Сделать резервную копию. Выполнить `scripts/release-to-desktop.ps1`.
2. Обновить **только компонент** файлом `com_minimarket-0.5.63.zip`. Проверить новую главную и залитую кнопку каталога.
3. **Отдельно** установить `mod_minimarket_quicklink-0.5.63.zip` через менеджер расширений Joomla. Если он был установлен раньше, это обновление модуля.
4. Проверить верхнюю правую панель: корзина MiniMarket должна быть **непосредственно слева от версии Joomla** и оформлена как штатная кнопка. На узком экране может автоматически перемещаться в меню «…» Atum.
5. Параметры модуля: **Материалы → Модули панели управления → MiniMarket**. Можно изменить текст, отображение иконки, публикацию и позицию. Выключить и повторить обновление — пользовательская настройка должна сохраниться.
6. Демонстрационный SQL для этих изменений **не импортировать**: он нужен лишь для тестового каталога при необходимости.
