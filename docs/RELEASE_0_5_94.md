# MiniMarket 0.5.94 — фиды: две синхронные колонки, независимый фильтр товаров

**Источник:** замечание к экрану фидов от 11.11.2026.

## Интерфейс

- Слева — название «Категории» и кнопки выделить/снять всё, сразу под ними строка поиска категорий и окно с деревом для включения категорий в фид.
- Справа на той же высоте — «Товары» и кнопки выделить/снять всё, сразу под ними **одна строка**: поиск товаров и справа компактная кнопка фильтра категорий. Окно товаров начинается ровно после этой строки.
- Фильтр категорий товаров раскрывается поверх списка, не раздвигая его вниз. Внутри — чекбоксы для выбора нескольких категорий (OR) и «Сбросить фильтр».
- Фильтр справа меняет **только видимость товаров в списке**, не меняет отмеченные слева категории, сохранённый набор товаров и режим `auto/manual`. Поиск по названию/SKU объединяется с категориями по AND. Выбор всех/снятие работает только по видимым строкам; при ручном изменении товаров переключается на ручной режим, как раньше.
- HTML использует Joomla/Bootstrap 5 формы и кнопки без самодельной системы оформления; RU/EN переводы, compact dark/light стиль. На узком экране стандартная колонка Bootstrap складывается вертикально.
- Данные фида, серверный алгоритм отбора, URL, Sitemap, настройки публикации и база **без изменений**.
