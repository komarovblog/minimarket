# MiniMarket 0.5.34 — приёмка общего справочника опций и исправления CheckboxesField

**Только локальная Joomla после успешного GitHub Actions и backup базы minimarket.** Перед обновлением сделать SQL backup, так как `0.5.34.sql` добавляет три новые таблицы; предыдущие SKU и товары не изменяются.

## Что должно быть реализовано к 0.5.34

- MiniMarket → **Опции**: нативный список Joomla с названием, кодом, количеством значений, статусом, ID, фильтрами, массовой публикацией.
- Новая опция → Основное (Название, необязательный код, статус, порядок) → Значения (штатные +/−/перемещение, значение, необязательный код, HEX если цвет).
- Категория → вкладка **Опции**: для каждой общей опции выпадающий список «Наследовать / Не использовать / Необязательно / Обязательно». Изменение категории не переписывает SKU.
- «Связи товаров» и «Товары в связи» с чекбоксами: **нет Warning stdClass::$checked**, сохранённые флажки выставляются снова при открытии, сброс/сохранение не портят другие связи.

**Важно:** выбор глобальных опций в самом товаре и новая матрица активных сочетаний — **A1/A2, ещё не готовы**. Старая локальная форма SKU пока сохраняется, чтобы не удалить торговые данные. Бренды, коллекции и рекомендации — B/C, тоже не готовы. Не заявлять, что эти разделы существуют до реальной реализации.

## Ручная проверка

1. После установки открыть **Связи товаров → связь с товарами**; PHP Warning отсутствует, выбранные товары отмечены. Снять/добавить флажок, сохранить, снова открыть — оба состояния сохранены.
2. Открыть **Товары → существующий товар → Связи товаров**; существующие связи помечены, можно добавить другую. Сохранение товара без изменения опций не меняет прежние SKU/галереи/цены.
3. Открыть **Опции → Создать**. Название «Размер», код `size`; значения S (`s`), M (`m`), L (`l`). Сохранить, открыть снова: один и тот же `option_id`, те же три `value_id`, значения и порядок.
4. Создать «Цвет» со значениями «Красный» (`red`, HEX `#FF0000`) и «Синий» (`blue`, HEX `#0000FF`). При повторном сохранении значения сохраняются; второй одинаковый код не допускается.
5. В категории «Футболки» → вкладка **Опции** назначить «Размер — Обязательно», «Цвет — Необязательно». Сохранить и открыть снова — выбор сохраняется.
6. Создать вложенную категорию, открыть вкладку «Опции» — наследуются правила родителя. Переопределить «Размер — Не использовать»; новая настройка действует только в дочерней категории. Повторно открыть родителя: его правило не менялось.
7. В другой категории выбрать тот же «Размер» и убедиться, что его значения S/M/L не требуют повторного создания.
8. Проверить русскую/английскую локализацию, тёмную и светлую темы, отсутствие предупреждений. Проверь массовую публикацию опций и отсутствие дублей после обновления.

**При ошибке:** снять скриншот и указать, какая вкладка/действие; не запускать SQL вручную без анализа. Результаты CI не равны проверке в локальной Joomla.
