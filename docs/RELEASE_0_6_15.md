# MiniMarket 0.6.15 — себестоимость и фактические затраты доставки

## Функциональность
1. **Товар → Основное** (только администраторам \`core.admin\`): поле «Себестоимость единицы». Пусто означает неизвестно; явный 0 — подтверждённую нулевую себестоимость. Цена продажи не меняется. Виртуальные комплекты: стоимость складывается из существующих компонентов в момент оформления заказа, а не из отдельной выдуманной стоимости комплекта. Для текущей модели опций себестоимость SKU наследует товар. При неизвестном компоненте стоимость заказа не рассчитывается.
2. **Заказ → Товары** (только \`core.admin\`): исторический снимок себестоимости строк, товаров после скидки и предварительная разница по товарам. Не называть разницу чистой прибылью: нет фактических расходов доставки, эквайринга, рекламы, налоговых корректировок и возвратов. Старые заказы сохраняют NULL, никакого backfill из текущих цен.
3. **Доставка → Основное** (только \`core.admin\`): отдельная форма подтверждения реального расхода с документом/основанием, датой и автором. Коррекция меняет текущую сумму одной Shipment, сохраняя неизменяемую историю версий, которая не суммируется как расходы. Сумма для покупателя в исходном заказе не меняется. В «Заказ → Доставка» показывается общий расход всех Shipment только при наличии подтверждённой суммы для каждой.
4. Нет новых модулей, плагинов, складского журнала, изменения оплаты/возвратов, интеграции перевозчика или новых статусов.
5. Операции над себестоимостью и расходами разрешены администратору; для будущих финансовых ролей нужно отдельное ACL-решение. Соответствующие поля закрыты от оператора без \`core.admin\` в UI и в POST.

## Миграция
\`admin/sql/updates/mysql/0.6.15.sql\` — аддитивные nullable поля и \`#__minimarket_shipment_cost_revisions\`; \`install.mysql.sql\` обновлён аналогично. Ручной импорт demo SQL и backfill **запрещён**. Joomla upgrade выполняет миграцию. Сделать backup.

## Проверки
\`scripts/test-0-6-15-commerce.php\` — регрессия прав, источников, NULL vs 0, финансовых отображений и отсутствия движений склада.
\`scripts/test-0-6-15-commerce-mysql84.php\` — настоящая migration на отдельных временных таблицах MySQL 8.4, с сохранением старых строк и отличием неизвестного от нуля.
Дальше PHP и Windows ZIP CI; браузерная приёмка Joomla 6/Atum отдельно.
