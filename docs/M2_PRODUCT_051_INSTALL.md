# MiniMarket 0.5.1 — установка ZIP с номером версии

**Причина перевыпуска:** пользователь видит старую форму товара (без вкладок) в Joomla 6.2.0, несмотря на исходники 0.5.0. Отсутствие вкладок в браузере подтверждено скриншотом, но причина (устаревший установленный ZIP, обновление или кэш) пока не доказана.

Этот выпуск **не меняет бизнес-данные** и не добавляет таблицы. Номер версии компонента повышен до **0.5.1** для однозначного определения архива и установки. В ZIP есть вся реализация товарных редакторов 0.5.0. Миграция 0.5.0 остаётся доступной для Joomla updater, если ещё не была применена.

## Одно обновление

1. Сохранить резервную копию БД локальной Joomla. Не удалять установленный компонент.
2. В `C:\OSPanel\home\minimarket.local` выполнить:
```bat
git pull --ff-only origin development
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\inspect-package.ps1
```
3. Ожидается **`PACKAGE_OK: 0.5.1 (com_minimarket-0.5.1.zip)`**. Только тогда установить **`dist\com_minimarket-0.5.1.zip`** через Joomla → Система → Установка → Расширения. Не выбирать прежний `com_minimarket.zip`.
4. После установки открыть MiniMarket → Товары → Создать. Вверху должны быть 5 вкладок: Основное, Описания, Изображения, SEO и соцсети, Публикация. В «Изображениях» должны быть **Обложка товара** (Joomla Media) и Alt. Сохранение реального товара TEST-001 для этой проверки не требуется.
5. Проверить номер версии компонента в Joomla → Система → Управление → Расширения (поиск MiniMarket): **0.5.1**. *6.2.0 в верхнем интерфейсе — версия Joomla, не MiniMarket*.
6. Если старая форма всё ещё на экране после установки **с подтверждённым PACKAGE_OK**: зафиксировать симптом и проверить, что Joomla реально обновила установленный файл `public_html/administrator/components/com_minimarket/forms/product.xml`. Не менять core, не удалять компонент/БД/товары и не запускать ручной ALTER.

ZIP можно также найти как artifact в GitHub Actions последнего зелёного билда `development` (внешний artifact архивирует собственно номерной ZIP). Содержимое проверяется CI Windows package job. **Реальный browser smoke ещё NOT RUN**.

Отдельная следующая задача — полноценная галерея из нескольких фото товара. Кликовость и размещение изображения категории отложены по решению пользователя.
