# MiniMarket 0.5.67 — три полноширинные полосы, нативные плитки Joomla

Дата: 07.11.2026. Ветка `development`. Joomla 6 / Atum, PHP 8.4–8.5.

## Исправления после просмотра пользователем 0.5.66

1. **Возвращены три полноширинные панели друг под другом:** «Управление», «Магазин», «Инструменты». Убраны `mm-dashboard-grid` с двумя колонками панелей и ограничение `max-width:1120px`. Панели и верхняя кнопка занимают всю доступную ширину содержимого Joomla, в том числе при свёрнутом меню.
2. **Адаптивная сетка самих плиток:** 1 на мобильных (до 767px), 2 на планшетах (768–1199px), 4 на десктопах с открытым меню, 6 на десктопах со свёрнутым меню. При сворачивании Joomla меняет класс `#wrapper.closed` — стили реагируют на него без JavaScript и без модификаций Joomla. Пустые места остаются только там, где естественно не хватает плиток (например, в «Управлении» одна будущая кнопка «Заказы»), а не справа от целой панели.
3. **Текст под значком:** каждая плитка выводит сверху иконку слева и счётчик справа; ниже — название раздела. Шрифт 0.875rem / 600, как в навигации, без прежнего переноса каждого слова в несколько строк. «Комплекты» сохраняют отдельную SVG-иконку.
4. **Цвет:** почти нативный приглушённый серо-графитовый Atum (`#272e36`), без яркой синей заливки, со спокойным hover/focus.
5. Реальные 10 счётчиков, прочерки «Заказы» и «Импорт / Экспорт», существующие переходы, кнопка каталога, независимый toolbar и другие разделы не изменяются.

## Поставка

- `com_minimarket-0.5.67.zip` — готовая установка поверх 0.5.66;
- `mod_minimarket_toolbar-0.5.67.zip` — отдельный модуль, переустановка для этого изменения не требуется;
- `minimarket_mysql84_nnop3_update_0_5_67.sql` — та же накопительная демобаза, что в 0.5.66, без миграции. **Для обновления UI SQL не импортировать.**

Команда на Windows: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\OSPanel\home\minimarket.local\scripts\release-to-desktop.ps1"`.

## Тесты и приёмка

Актуализированы регрессии 0.5.64/0.5.65/0.5.66 и общий тест нативного UI; добавлена проверка `scripts/test-0-5-67-dashboard-responsive.php` (три секции, 1/2/4/6, `#wrapper.closed`, размеры и цвета, значки и счётчики). CI собирает раздельные ZIP и проверяет MySQL 8.0/8.4, PHP 8.4/8.5.

После установки пользователь проверяет настоящую Joomla 6.2/Atum: открытое меню — четыре плитки, свёрнутое — шесть, панель растянута до правого края. **Автоматический браузерный E2E в живой Joomla по-прежнему не настроен.**
