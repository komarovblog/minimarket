**Подтверждение пользователя 01.11.2026:** в Joomla после установки 0.5.2 выбранное изображение отображается чистым путём без `#joomlaImage://`, также после сохранения и повторного открытия. **Этот точечный сценарий: PASS.** Остальные пункты широкой приёмки не считать автоматически подтверждёнными; SQL CI PASS не доказывает миграцию на рабочем сайте.

# MiniMarket 0.5.2 — чистые пути изображений

**Что изменилось:** при выборе изображения оставляем только `images/имя.png`, не показываем `#joomlaImage://...width=...&height=...`. Так же для категории, товара и Open Graph. В 0.5.2 сервер сам удаляет служебный хвост при сохранении, а штатное SQL-обновление очищает старые строки в 4 колонках. Файлы, цены, SKU, ID и остатки не меняются.

## Установка одной версией

1. После полного PASS GitHub CI сделать **резервную копию БД** локальной Joomla.
2. В CMD в `C:\OSPanel\home\minimarket.local`:
```bat
git pull --ff-only origin development
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\inspect-package.ps1
```
3. Ожидается `PACKAGE_OK: 0.5.2 (com_minimarket-0.5.2.zip)`. Joomla → Система → Установка → Расширения → выбрать **`dist\com_minimarket-0.5.2.zip`**. Не удалять существующий компонент, не запускать SQL вручную.
4. Открыть MiniMarket → Товары → Создать → Изображения. Выбрать `powered_by.png` через Joomla Media, проверить **сразу после выбора** строку `images/powered_by.png` без `#joomlaImage`. Нажать Save на отдельной тестовой карточке, открыть снова, проверить чистый путь и корректное фото на витрине.
5. В категориях повторить выбор обложки и Open Graph-изображения, в товаре также проверить OG. Перепроверить существующие карточки: URL, SKU, цена, остаток и категория не изменились. В управлении расширениями Joomla версия MiniMarket должна быть 0.5.2.
6. Если сложный путь виден после выбора/после Save, указать **на каком этапе**. Не переустанавливать Joomla, не чистить БД, не менять ядро. Прислать короткий симптом/скриншот.

**Автоматические тесты != Joomla runtime:** браузерная проверка ещё не проведена. Принцип для будущих галерей и вариантов — [MEDIA_PATH_POLICY.md](MEDIA_PATH_POLICY.md).
