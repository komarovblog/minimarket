# MiniMarket 0.5.46 — исправление ссылок сущностей в Joomla admin

Дата: 04.11.2026. Ветка `development`; Joomla 6; ядро не меняется. Версия содержит только исправление ссылок, документы и тесты; **SQL-миграции отсутствуют**.

## Причина
В ряде HTML-полей и на стартовом экране URL формировался через `Joomla\CMS\Router\Route::_($url)` с параметром `$xhtml=true` (по умолчанию), а затем дополнительно пропускался через `htmlspecialchars()`. В результате `&amp;` превращался в `&amp;amp;`. После одного HTML-декодирования браузером Joomla получала параметры `amp;task`, `amp;id` или `amp;view` вместо `task`, `id` и `view`. Отсюда переход на главную страницу MiniMarket вместо нужной сущности.

## Исправление
- Новый `Administrator\Service\AdminEntityLinks` формирует валидированные цели через `Route::_($url, false)` и **один раз** выполняет `htmlspecialchars()`.
- Категория → характеристика, категория → опция, товар → характеристика, связи → связь/товар, пустой список опций → создать опцию, кнопка категорий в редакторе товара и ссылки разделов главной переведены на общую функцию.
- Ссылки `task=attribute.edit&id=N`, `task=orderoption.edit&id=N` сохраняют штатный Joomla FormController (контроль прав, edit state, переход на layout=edit). Переходов на `view=attribute&layout=edit&id=N` в обход стандартной проверки нет.
- Общая матрица SKU, галерея, товары, характеристики, опции, ID, БД и публичные URL не изменяются.

## Приёмка
После установки `com_minimarket-0.5.46.zip` поверх 0.5.45:
1. Категории → открыть категорию → нажать **название характеристики**. Должен открыться редактор именно выбранной характеристики, с правильными ID и полями.
2. Аналогично нажать **название опции** — открывается выбранная опция.
3. Товар → Характеристики → «Редактировать значения» — открывается нужная характеристика.
4. Связи → участник — открывается нужный товар/связь.
5. Главная MiniMarket → перейти по разделам «Категории», «Характеристики», «Опции» — открывается именно список раздела, не стартовый экран.
6. Вернуться из редактора, сохранить характеристики и проверить, что данные не потерялись. Обновить через Ctrl+F5.

## Автоматические тесты
`scripts/test-admin-entity-links.php` симулирует Joomla `Route::_`, HTML-экранирование и один проход HTML-декодирования браузером; проверяет `task`, `id`, `view`, `add`, отсутствие `amp;task`, отклонение неразрешённых целей. Подключён к PHP CI. Ручная проверка Joomla отдельно обязательна.

## Выпуск
`git pull --ff-only origin development`; затем `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1` и `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\inspect-package.ps1`.
В `dist` два файла: `com_minimarket-0.5.46.zip` и отдельный `minimarket_toys_rich_import.sql`. **Demo SQL НЕ импортировать при upgrade** — это сценарий замены тестового каталога.
