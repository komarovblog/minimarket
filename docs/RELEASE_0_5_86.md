# MiniMarket 0.5.86 — единые списки Joomla 6 (11.11.2026)

## Эталон
«Товары»: верхняя нативная Joomla Toolbar, SearchTools, таблица с выбором столбцов, ограничения ширины, массовые действия с подтверждением. Внутренние повторные заголовки в списках не показываются.

## Что изменено

- **Заказы**: кнопки Joomla сверху «Создать», «Подтвердить», «Отменить», «Удалить» (в обратимую корзину, **только отменённые**). Для корзины — «Восстановить». Корзина вынесена в фильтр «Список заказов» вместе со статусом, методом доставки и поиском товаров по заказам. Поиск по номеру/покупателю/телефону/email, сортировка, лимит страницы.
- **Доставки**: сверху «Создать», «Доставлено», «Отменить»; поиск по треку, номеру заказа/доставки, покупателю, телефону, городу. Нет физического удаления отправлений.
- **Отзывы**: сверху «Создать», «Опубликовать», «Отклонить»; поиск по автору, заголовку, тексту и товару, фильтр статуса.
- **Промокоды и SEO-страницы**: штатные верхние кнопки «Создать», «Опубликовать», «Снять с публикации»; поиск, состояния, сортировка, лимит, чекбоксы.
- **Фиды**: верхнее «Создать», фильтры, поиск, сортировка, таблица; удаление фида остаётся в его строке, с CSRF и подтверждением.
- **Интеграции**: поиск реально установленных плагинов, фильтр состояния, ссылка на настройки в com_plugins. Демо-провайдеры не появляются.
- Семь нестандартных списков используют один PHP SearchTools partial и JS/CSS. Убраны повторные заголовки, добавлены компактные колонки, общий отступ и адаптивность.
- Десять уже нативных списков Joomla (включая «Товары», «Категории», «Характеристики», «Значения») получили локальный горизонтально прокручиваемый контейнер. Весь экран по горизонтали прокручиваться не должен.
- Исправлена непереведённая надпись `JOPTION_SELECT_ALL` в фильтре товаров.
- Массовые действия требуют ACL, CSRF, существующие ID и допустимые состояния, выполняются одной транзакцией. Заказы и цены не удаляются.

## Регрессии и ограничения

- Структурная проверка: `scripts/verify-admin-lists.ps1`. Проверяет наличие единых оболочек, таблиц, поиска, контроллеров и верных namespace; запускает PHP lint, если PHP в PATH.
- `scripts/release-to-desktop.ps1` запускает проверку до сборки и копирует на рабочий стол два отдельных ZIP и соответствующий версии накопительный SQL. SQL — необязательный **демокаталог**, не обновление схемы.
- **В этой версии нет новых изменений схемы.** Установщик продолжает использовать миграцию 0.5.85 как последнюю SQL-миграцию. Не импортировать демонстрационный SQL для правок интерфейса.
- Браузерная проверка локальной Joomla (90/100/125/150%, светлая/тёмная тема, RU/EN), тестирование массовых действий, повторная проверка БД и работа физического ZIP в этой среде не выполнялись. Нельзя объявить релиз принятым до них.
- Пункты, не входящие в этот UI-проход: продвинутые тарифы доставки, полный SEO-фильтр и применение промокодов при оплате. Ошибка Joomla Database Maintenance около `AND 'null' = 'NO'` пока не подтверждена устранённой. Не запускать автоматическое «Исправить» без резервной копии.

## Локальная сборка (CMD, одна строка, из корня проекта)

```cmd
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "git pull --ff-only origin development; if ($LASTEXITCODE -ne 0) { exit 1 }; & '.\scripts\release-to-desktop.ps1' -SkipPull"
```

Установить `com_minimarket-0.5.86.zip` в Joomla → Система → Установка → Расширения. Самостоятельный `mod_minimarket_toolbar-0.5.86.zip` устанавливать/обновлять отдельно, если используется.

## Локальная приёмка
1. Открыть «Товары», «Заказы», «Доставки», «Отзывы», «Промокоды», «SEO-страницы», «Фиды», «Интеграции». Заголовок только в шапке Joomla; toolbar одинаково расположен; поиск, фильтры, таблица, переключатель столбцов и пагинация — на одной вертикальной сетке.
2. Проверить каждый список при 90, 100, 125 и 150% масштаба, с открытым и свёрнутым левым меню; горизонтальная прокрутка только внутри таблицы или переход к карточкам на узком экране.
3. Заказы: выбор 2 строк → подтверждение; отмена; «Удалить» только отменённые; режим «Корзина» в фильтрах → восстановление; нельзя отправить в корзину активный заказ.
4. Доставки: реальные записи, поиск по треку/заказу, массовое «Доставлено» и «Отменить», без удаления.
5. Отзывы, промокоды, SEO: массовые публикации/отключения, права, CSRF, результаты после перезагрузки.
6. Нативные товары/категории/бренды и т. д. — проверка сортировки, поисковых фильтров и выбора столбцов после помещения таблиц в scroll-контейнер.
