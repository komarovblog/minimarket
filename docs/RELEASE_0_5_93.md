# MiniMarket 0.5.93 — показывать характеристику/опцию в карточке товара категории

## Выполнено в исходниках

У каждой **прямой привязки** характеристики или опции к категории теперь есть независимая галочка «Показывать в карточке товара в списке». Она находится в существующем списке привязок на вкладке «Характеристики» / «Опции», рядом с выбором «Наследовать / Включить / Обязательно / Отключить», без отдельного раздела и без второй модели связей.

- Галочка активна только при прямом режиме «Включить» или «Обязательно»; при «Наследовать» и «Отключить» она лишь отражает наследуемое значение, не подменяя режим.
- Вложенные категории наследуют флаг родительской связи. Прямая привязка дочерней категории может включить или выключить его независимо.
- Не влияет на значение в карточке товара, выбор в фильтре, обязательность свойства, SKU, остатки и заказы. Только список товаров.
- Сохранение в существующих таблицах `#__minimarket_category_attributes` и `#__minimarket_category_order_options`, новое поле `show_in_list`.
- **Никакие существующие записи не скрываются при обновлении:** новое поле `DEFAULT 1`; обратные редакторы атрибутов/опций сохраняют уже заданный флаг.
- Joomla 6 native Form, RU/EN переводы, небольшое компонентное JS только для доступности чекбокса. Класс Bootstrap и стили Joomla используются без самодельных панелей.
- Реальная витрина читает `show_in_list`: `ProductAttributeCatalog::load(...,'category')` и `View/Category/HtmlView.php` для товарных опций. На странице конкретного товара данные не фильтруются этим параметром.

## База данных и совместимость

Новая Joomla migration: `admin/sql/updates/mysql/0.5.93.sql`, две аддитивные колонки в связях. `install.mysql.sql` обновлён для чистой установки. Удаления таблиц и старых настроек нет. Входные данные прошлых версий для режимов связей совместимы; полная миграция обязательна до открытия новой формы.

Проверка: `scripts/test-category-list-visibility.php` (наследование, безопасность входа, фронтенд-контракт), `scripts/test-public-product-attributes.php` (разные страницы вывода), `scripts/test-category-schema.php` (MySQL обновление старых таблиц без потери режимов + fresh), CI PHP 8.4 и 8.5, Windows ZIP и MySQL 8.4. Для релиза версия `0.5.93`, `sample-data/minimarket_mysql84_nnop3_update_0_5_93.sql` остаётся **только опциональной демонстрационной базой** и никогда автоматически не импортируется.

## Что проверить в браузере Joomla

1. В категории включить характеристику и опцию, отключить у них «Показывать в карточке товара в списке». Сохранить/открыть форму снова.
2. На странице категории товара эти свойства исчезли из карточки в списке; в полной карточке товара, фильтре и выборе SKU всё осталось.
3. У родительской категории выключить показ и убедиться, что дочерняя наследует; в дочерней задать самостоятельную привязку и включить.
4. Открыть и сохранить ту же характеристику/опцию через их собственный редактор; флаг категории сохранился.
5. Сравнить RU/EN, светлую/тёмную тему и разные масштабы. Проверить, что список и фильтры не сместились.

## Что не вошло в этот выпуск

**SKU export/import v2** — отдельный следующий сквозной этап. По согласованному контракту одна строка = один продаваемый SKU, общие данные товара дублируются, информационные атрибуты и опции — отдельные колонки. Не изменять экспорт/импорт v1 до появления безопасного парного v2. Другие открытые задачи: конструктор сочетаний, системные фильтры по полям, расширенные поля оформления и подтверждение.
