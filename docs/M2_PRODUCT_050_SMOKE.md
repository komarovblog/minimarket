# MiniMarket 0.5.0 — один тест на действующей Joomla

**01.11.2026.** GitHub CI PASS. Joomla runtime пока NOT RUN.

## Подготовка и установка

1. Сделать резервную копию БД Joomla. Не удалять компонент и не переустанавливать Joomla.
2. CMD в каталоге C:\OSPanel\home\minimarket.local — выполнить git status --short. Не сбрасывать изменения .osp/project.ini.
3. Выполнить git pull --ff-only origin development.
4. Запустить PHP 8.5 тесты: scripts/test-product-editor.php, scripts/test-catalog.php, scripts/test-router.php, scripts/test-admin-options.php (исполняемый PHP: C:\OSPanel\modules\PHP-8.5\php.exe).
5. Запустить сборку: powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
6. Проверить: powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\inspect-package.ps1
7. Ожидается PACKAGE_OK: 0.5.0. После PASS обновить MiniMarket через Joomla → Система → Установка → Расширения файлом dist/com_minimarket.zip поверх установленного компонента. **Не выполнять SQL в phpMyAdmin.** Скрипт test-category-schema.php запускать только в отдельной CI MySQL, никогда на пользовательской базе.

## Проверка

1. Открыть действующий TEST-001. Зафиксировать его ID, SKU, цену, остаток, категорию и URL без редактирования.
2. MiniMarket → Товары: проверить новые колонки и фото, отсутствие картинки, поиск по названию/артикулу/ID, выбор категории/публикации, сортировки. При большом числе товаров — пагинация.
3. Создать отдельный тестовый товар. Заполнить цену, остаток, категорию; два Joomla Editor с жирным текстом и списком, изображение и alt, статус. Сохранить и открыть снова. Данные должны остаться.
4. Проверить на публичной карточке обложку, оба HTML-описания, актуальную цену/SKU/остаток, постоянный плоский URL. Проверить фото в каталоге и списке товаров категории.
5. Заполнить SEO title, meta description, noindex,follow, OG title/description/image. Проверить HTML head и один canonical. Удалить overrides и убедиться, что fallback восстановился.
6. В отдельном тестовом товаре попробовать отрицательную цену, отрицательный/дробный остаток, внешний путь изображения, неверный robots: валидация должна запретить сохранение.
7. Снять с публикации только тестовый товар, проверить публичный 404 и возможность восстановить запись в админке.
8. Проверить TEST-001: после обновления все исходные поля, URL и его категория не изменились. Проверить меню Shop, категории версии 0.4.2 и SEO.

При проблеме указать номер шага, URL и краткий симптом/скриншот, не редактировать БД вручную. PASS только после реального Joomla smoke. Variants, галереи, бренды, фиды и Schema.org не входят в 0.5.0.
