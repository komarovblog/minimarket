# MiniMarket 0.6.14 — главная панель

**Репозиторий:** komarovblog/minimarket, ветка development. Релиз интерфейса, без изменения схемы и данных каталога.

## Результат

На главной панели Joomla Atum «Отчёты» следуют сразу после «Управления». Полный порядок: Управление → Отчёты → Магазин → Маркетинг → Инструменты → Настройки. «Отчёты» содержат пока только карточку «Остатки».

«Платежи» уже находились в «Управлении» четвёртой карточкой, поэтому новая карточка не дублируется. У существующей плитки исправлена отсутствовавшая на скриншоте иконка: та же локальная SVG-иконка банковской карты, что у «Способов оплаты». Маршрут payments и исходный счётчик платежных обязательств (количество действующих заказов) сохраняются без изменения.

Меню слева, пресет Joomla, стиль Atum, сетка 1/2/4/6 колонок, SQL, регистрация, склад, заказы, оплата, доставка и возвраты не изменены. Языковые ключи уже существуют на русском и английском.

## Проверки и выпуск

Регрессионный тест scripts/test-0-6-14-dashboard.php проверяет порядок шести групп, единственную карточку payments, локальный SVG, корректную ссылку stockreport, неизменность счётчика и адаптивность. Он подключён к CI; предыдущие тесты dashboard и навигации остаются обязательны.

SQL admin/sql/updates/mysql/0.6.14.sql — только SELECT 1. Демоданные и таблицы не меняются. Сопутствующий demo SQL не нужен для обновления и не должен импортироваться.

Стандартная команда для локальной сборки:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\OSPanel\home\minimarket.local\scripts\release-to-desktop.ps1"

Выходной установочный архив: com_minimarket-0.6.14.zip.

Реальная браузерная приёмка после установки Joomla 6: RU/EN, тёмная/светлая темы, узкий экран и десктоп, порядок двух первых полос, видимость SVG, ссылка «Платежи», счётчик, переход на «Остатки». Автоматические тесты не заменяют проверку в браузере.
