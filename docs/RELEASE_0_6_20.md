# MiniMarket 0.6.20 — Автоматические товарные акции

**Изменения:** C07 из утверждённой дорожной карты. Новый раздел **Маркетинг → Скидки** в трёх местах навигации: системное левое меню, меню компонента Joomla, главная панель. Действительный счётчик всех акций. Список в стиле Joomla SearchTools с фильтром публикации, компактной таблицей и массовой сменой статуса. Нативный редактор с вкладками «Основное», «Условия», «Ограничения» и «Публикация», с зависимыми полями. Для выбора товаров/категорий/брендов — общий поисковый picker, не ручные ID.

**Сервер:** `AutoDiscount::normalize` проверяет название, диапазон дат UTC, сумму с точностью до копеек, проценты в базисных пунктах, цель и действительность ID. `AutoDiscount::quote` выбирает одно правило с наибольшей выгодой (при равенстве — меньший ID) и ограничивает скидку допустимой стоимостью товаров. Условия распространяются на прямую категорию товара, бренд или индивидуальные ID; вложенные категории не подразумеваются автоматически.

**Промокоды:** не суммируются с автоматическими акциями. Если явно введённый промокод даёт столько же или больше — он выбирается и регистрируется как раньше. Если автоматическая акция выгоднее — заказ использует её, а промокод не списывается. Ошибочный промокод по-прежнему вызывает ошибку валидации, даже когда есть автоматическая скидка.

**Заказ:** `#__minimarket_orders.auto_discount_id` и снимок `auto_discount_title` сохраняются для новых заказов; не пересчитываются исторические заказы. Суммы отображаются в корзине и checkout до подтверждения, затем пересчитываются и фиксируются на сервере при создании заказа.

**SQL:** `admin/sql/updates/mysql/0.6.20.sql` — аддитивная миграция новой таблицы акций и двух столбцов заказов, без пересчёта остатков или финансовых записей. `install.mysql.sql` обновлён. Демоданные вручную не импортировать. Сделать backup перед установкой.

**Регрессия:** `scripts/test-0-6-20-auto-discounts.php`, `scripts/test-0-6-20-auto-discounts-mysql84.php`, старые PHP 8.4/8.5, MySQL 8.4 и Windows ZIP. Первичный полный CI: [6/6 PASS](https://github.com/komarovblog/minimarket/actions/runs/43455586740). Последующие коммиты тестируются отдельно. Браузерная приёмка Joomla 6/Atum ещё не подтверждена.

**Выпуск:** `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\OSPanel\home\minimarket.local\scripts\release-to-desktop.ps1"`. Установочный компонент `com_minimarket-0.6.20.zip`. SQL upgrade выполняет Joomla.

**Дальше по утверждённому плану:** C08 управляемые рекомендации, C11 документы и фискализация (только реальные поставщики/чеки), C12 план-факт и маркетинговая аналитика при наличии подтверждённых данных.
