# MiniMarket 0.5.16 — публичные характеристики и обязательность по категории

Статус: код в `development`, GitHub CI и ZIP см. последний workflow; проверка Joomla в реальном браузере выполняется отдельно.

## Характеристики на странице товара

Ранее публичная Product HtmlView загружала только карточку, изображения и видео; теперь после проверки статуса товара и цепочки опубликованных категорий загружается набор разрешённых характеристик. Вывод — семантическая таблица название/значение, адаптивная, без привязки к шаблону. Опубликованные значения `list/color`, scalar и множественный текст; цветовые и текстурные образцы; единицы чисел; `boolean=0` — Нет; HTML очищается Joomla; файлы разрешённых локальных расширений выводятся ссылкой. По пять пакетных SQL-запросов независимо от количества характеристик, без N+1.

## Правило обязательности

В карточке **Категории → Характеристики** и **Характеристики → Категории** одно состояние на пару: Наследовать (-1), Не используется (0), Необязательная (1), Обязательная (2). Direct rules в БД хранятся как enabled (0/1) + required (0/1). Новая аддитивная миграция `0.5.16.sql` добавляет `required DEFAULT 0` для всех старых назначений. При смене родительской категории режим наследуется от ближайшего предка, а прямое правило переопределяет.

В редакторе товара обязательные свойства помечаются «*». Сервер `ProductAttributes::normalize` проверяет обязательные ID по фактической категории в момент сохранения. Пустые, пропущенные, пустой множественный список -> ошибка с названием свойства; 0, Нет, хотя бы один пункт -> заполнено. Уже созданные товары не изменяются массово: при следующем сохранении должны выполнить актуальные требования категории. Изменение правила не удаляет связанные значения.

## Проверки Joomla (после резервной копии и установки ZIP поверх)

1. Создать категорию «Камины» и текстовый атрибут «Материал», назначить «Обязательная». В товаре пропустить -> отказ сохранения; выбрать «Металл» и «Камень» -> сохранение; оба отображаются на сайте.
2. Создать дочернюю категорию: режим «Наследовать» -> «Материал» обязателен; выбрать «Необязательная» -> допустимо не заполнять; «Не используется» -> не выводится; вернуть «Обязательная» -> снова проверяется.
3. Через вкладку «Категории» самой характеристики изменить режим; убедиться, что в категории виден тот же режим.
4. Для числа и Да/Нет проверить, что `0` и «Нет» удовлетворяют обязательности; для списка нельзя оставлять пусто.
5. Убедиться в сохранности всех ранее введённых товаров, SKU, фотографий, видео, цен и URL; проверить версии RU/EN.
6. Очистить кеш Joomla после установки и открыть товар на сайте; убедиться в выводе блока «Характеристики».

Интеграционный Joomla browser smoke не эквивалентен успешному CI; не объявлять PASS до фактического теста.
