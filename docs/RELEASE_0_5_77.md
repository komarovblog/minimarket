# MiniMarket 0.5.77 — одна характеристика на товар

## Изменения

1. В карточке определения характеристики на вкладке **Характеристика** убрано поле «Выбор значений». Каждая характеристика товара может иметь только одно сохранённое значение — текст, число, цвет, один пресет, Да/Нет, HTML или документ. Для товарных опций/SKU эта настройка ничего не меняет: варианты размеров и цветов продолжают работать отдельно.
2. Вкладка **Фильтр** остаётся независимой: чекбоксы отображаются без «(несколько)», отдельный флаг «Множественный выбор в фильтре» разрешает выбирать несколько значений одного фильтра с логикой ИЛИ. Технический текст «Совместимость типов» убран.
3. В составе комплекта убрано повторяющееся «Цена за единицу» в строках, заголовок колонки — просто «Цена». Никаких изменений расчёта или выбора SKU.
4. Добавлена миграция базы 0.5.77.sql и ограничение уникальности для таблиц выбранных значений.

## Защита уже сохранённых данных

До обновления **обязательно выполнить полное резервное копирование** рабочей БД `minimarket`. Старые множественные характеристики не удаляются бесследно: миграция создаёт `#__minimarket_attribute_multivalue_archive`. В неё сохраняются все дополнительные предустановленные значения и **все** прежние ручные свободные значения. В активной карточке остаётся минимальный ID выбранного пресета либо первая ручная запись по порядку сортировки (сохраняется как скаляр). Сведения об альтернативных прежних значениях доступны в архиве для ручной проверки. Архив не относится к публичному каталогу.

Миграция запускается **автоматически установщиком Joomla** при обновлении с 0.5.76. Никаких чистых/накопительных SQL вручную не запускать. На MySQL DDL не полностью транзакционен, поэтому перед установкой нужен бэкап. При установке с нуля добавлены уникальные индексы и пустая таблица архива.

## Сборка

В CMD из `C:\OSPanel\home\minimarket.local`:
```bat
git pull --ff-only origin development
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\release-to-desktop.ps1 -SkipPull
```
На Desktop будут ровно три файла: `com_minimarket-0.5.77.zip`, `mod_minimarket_toolbar-0.5.77.zip`, `minimarket_demo_gallery_filters_0_5_77.sql`. Последний **не является миграцией**; при желании после проверки установленного компонента он дополняет демонстрационный каталог. Импортировать SQL можно только после бэкапа.
