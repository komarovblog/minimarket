# MiniMarket 0.5.58 — глобальные категории, адаптивная плитка и таблица комплектов

Дата: 2026-11-06. Ветка: `development`.

## Глобальные настройки

В Options / MiniMarket оставлена вкладка **Общие** (заголовок каталога, основной пункт меню, единый тип магазина). Добавлена вкладка **Категории**, содержащая:
- Показывать дочерние категории.
- Показывать свои товары и свои комплекты (сохранение ранее существовавшей независимой логики).
- Показывать товары и комплекты **из всех опубликованных вложенных категорий**, независимо друг от друга. По умолчанию оба выключены, чтобы не изменить прежний магазин.
- Отображение товаров: **Список** (по умолчанию) / **Плитка**.
- Количество карточек в ряд при плитке: телефоны (начиная с 0), планшеты (от 768px), ПК (от 992px), широкие экраны (от 1200px), допустимо 1..6, по умолчанию 1/2/3/4.

Существующая категория получила локальные настройки каждого флага, режима и четырёх чисел карточек. `Наследовать` (-1) означает **глобальное значение MiniMarket**, а не значение родительской категории. Существующие категории автоматически получают новые значения `inherit/-1` — никаких сбросов URL/SEO/данных.

Публичная категория использует Bootstrap 5 CSS-сетку (`row-cols-*`) и собственный `catalog-layout.css`, без изменения ядра Joomla или файлов шаблона. Joomla Cassiopeia уже использует Bootstrap 5; для нестандартных шаблонов проверяется подключение Bootstrap. Компонент остаётся пригодным для template overrides.

Скрытые/неопубликованные ветви вложенности не появляются в выдаче. Свои товары и товары из потомков управляются независимо; возврат исходного режима списка не удаляет контент.

## Комплекты — предыдущий незавершённый запрос

- Во вкладке **Состав комплекта** реальные колонки: Товар/SKU, Цена единицы, Количество, Сумма строки, кнопка «−» — общая сетка для существующих и новых строк.
- Во вкладке **Основное** при способе `Скидка от суммы товаров` показываются **Расчётная цена товаров** и **Цена комплекта со скидкой** под полем процента.
- В **Состав комплекта** те же названия; при фиксированной цене используется корректное название «Цена комплекта».
- JavaScript синхронизирует оба блока при изменении количества, состава, режима цены и процента. Состав и цены проверяются на сервере существующей бизнес-логикой.

## База и поставка

- Новая аддитивная миграция `admin/sql/updates/mysql/0.5.58.sql` добавляет 7 полей категорий. Она применяется Joomla при обновлении компонента.
- Новый `sample-data/minimarket_mysql84_nnop3_update_0_5_58.sql` — свежая версия **накопительного** демоимпорта, содержит весь предыдущий демонстрационный каталог. Не запускается при обновлении Joomla. Для изменений UI/настроек SQL-записи демоданных не требуются.
- Доставка — `scripts/release-to-desktop.ps1`, автоматически определяющий текущую версию. ZIP и SQL лежат рядом на рабочем столе. SQL не является миграцией и не является дампом рабочей БД.

## Проверки и ограничения

- PHP unit/contract: глобальные и локальные переключатели, наследование, допустимые значения колонок, дерево потомков, форма и перевод.
- MySQL 8.0 CI: обновление уже наполненной базы без изменения существующих колонок; MySQL 8.4 CI: полная схема и повторный накопительный SQL.
- PHP 8.4 / PHP 8.5, JavaScript syntax, Windows package check.
- Браузерный E2E на живой Joomla не выполнен — см. [TEST_STRATEGY.md](TEST_STRATEGY.md).

## Ручная приёмка Joomla 6.2

1. Установить компонент поверх 0.5.57 и проверить сохранение данных/SEO категорий.
2. Options: Общие/Категории. Сохранить `Плитка`, 1/2/3/4; проверить 375/768/1024/1440 px. Вернуть `Список`.
3. В родительской категории включить товары потомков, отключить комплекты потомков и убедиться, что выводятся только опубликованные обычные товары всех уровней; затем наоборот.
4. В редакторе одной категории изменить только количество карточек планшета и проверить отсутствие влияния на другую категорию.
5. В комплекте менять количество, скидку, переключать режим; два блока сумм должны совпадать. Перезагрузить форму и проверить сохранённый состав.
