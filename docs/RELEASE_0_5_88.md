# MiniMarket 0.5.88 — единый поиск, тарифы доставки, SEO и промокоды

**11 ноября 2026 · ветка `development` · PHP 8.5 / Joomla 6.2 / MySQL 8.4.**

## Выполнено в этой итерации

1. **Ручной заказ:** исправлена повреждённая HTML/PHP-разметка AJAX-поиска SKU. В поиск добавлен фильтр опубликованных категорий, как в редакторе состава комплекта. Категория передаётся серверному `productpicker.manualItems` и проверяется запросом, поиск по названию/артикулу остаётся серверным.
2. **Переводы:** в фильтре товаров убран потенциально нераспознанный `JOPTION_SELECT_ALL`. Новый собственный ключ `COM_MINIMARKET_PRODUCT_ALL_TYPES` задан в RU и EN. Все XML-фильтры дополнительно проверяются на использование сырого ключа. Создан `scripts/verify-translations.ps1`: проверка дубликатов, равенства ключей RU/EN, поиск необъявленных статических ключей в PHP/XML.
3. **Широкие таблицы:** товары и комплекты теперь при первом открытии показывают сокращённый набор столбцов в зависимости от доступной ширины. Остальные столбцы остаются доступны через «Столбцы», пользовательский выбор сохраняется. Версия настройки столбцов `v3` исключает старую сохранённую конфигурацию, оставлявшую все 12 столбцов открытыми. Усилен локальный горизонтальный скролл таблиц — страница не должна расширяться.
4. **Зоны доставки:** доработана карточка товара/комплекта — появились настройки веса (граммы) и объёма (см³), которые требуются серверному расчёту тарифов `за кг` и `за литр`.

## Что уже было добавлено в 0.5.87 и сохраняется в 0.5.88

- Справочник **Зоны доставки**: страна/регион/города/префиксы индексов, приоритет, фиксированная цена или базовый тариф + за начатый кг/литр объёма; минимум корзины, бесплатная доставка от суммы, ограничения веса/объёма, сроки, публикация. Расчёт производится на сервере при создании заказа. Самовывоз остаётся отдельным способом. СДЭК — только будущая интеграция, **не считать её API подключённым**.
- **SEO-лендинги**: редактирование, медиа и OG-изображение через Joomla Media, описание через Joomla Editor, опубликованные характеристики, SKU-опции, системные фильтры цены/наличия/артикула.
- **Промокоды:** фиксированный/процентный тип, сроки, минимум корзины, область действия, общий и персональный лимиты. Корзина и оформление заказа используют серверную проверку. Применения фиксируются только при успешном создании заказа в одной транзакции с записью заказа. Повторная попытка с тем же кодом заказа защищена уникальными ограничениями БД.
- **Общие пикеры сущностей:** доставка — выбор заказа с поиском и ограничением дат, отзыв — товар, SEO — категория, промокод — категория/товар; редактор комплекта и ручного заказа — поиск товаров/SKU. Выбранные ID валидируются на сервере.

## Установка

Из **CMD**, находясь в `C:\OSPanel\home\minimarket.local`, выполнить **одну строку**:

```cmd
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "git pull --ff-only origin development; if ($LASTEXITCODE -ne 0) { exit 1 }; & '.\scripts\release-to-desktop.ps1' -SkipPull"
```

На рабочем столе ожидаются `com_minimarket-0.5.88.zip`, `mod_minimarket_toolbar-0.5.88.zip`, `minimarket_mysql84_nnop3_update_0_5_88.sql`. Последний файл — **только необязательный демонстрационный каталог**, импортировать его ради интерфейса не нужно. Миграции БД `0.5.87.sql` выполняет установщик Joomla.
