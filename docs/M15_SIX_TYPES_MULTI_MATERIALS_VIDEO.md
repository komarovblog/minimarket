# MiniMarket 0.5.15 — шесть типов, множественные материалы и видео

Статус: source change, awaiting CI and Joomla browser smoke; working branch `development`.

## Товары и характеристики

Для вновь создаваемых характеристик доступны шесть типов: **Текст / Число / HTML-редактор / Да-Нет / Файл / Цвет**. Исторические `list`, `date`, `url`, `textarea` не удаляются и остаются редактируемыми, но не предлагаются для новых записей.

У типа **Текст** независимо выбираются свободный ввод или готовые значения. Для готовых значений есть **Одно / Несколько**. Например, у камина одновременно отмечены «Металл» и «Камень»: каждый выбор отдельная строка новой таблицы `#__minimarket_product_attribute_multi_values`, не CSV-строка. Сохранение происходит в транзакции с карточкой товара. Ранее сохранённый одиночный текст — скаляр и читается по-прежнему; при переходе на multi его можно перевыбрать и сохранить. Редактор защищает от повтора значений и от незаметного перехода Multi → Single, пока у товара более одного выбора.

Для текстовых presets допускается **необязательное изображение образца** через Joomla Media, хранящееся вместе с названием в совместимом JSON. Старые JSON-массивы строк читаются без миграции. Для цвета используется существующий справочник с неизменяемыми ID, HEX и новая `sample_image`. Образец — изображение фактуры или оттенка, не самостоятельный SKU. Реальный динамический фильтр и вариантные SKU ещё не реализованы; будущая витрина сможет отображать HEX/картинки в фасетах.

Файл: штатный Joomla Media (`types="documents"`), типизированный путь к разрешённым документам и безопасным вложениям, без загрузки двоичных данных в БД. HTML-редактор: штатный Joomla Editor и очистка HTML.

## Видео в карточке товара

Отдельная вкладка **Видео** повторяет галерею: плюс, удаление, перемещение. Источник: YouTube, RuTube, прямая HTTPS-ссылка на .mp4/.webm в облаке или Joomla Media (`types="videos"`), а также обложка (Joomla Media) и название. Храним ссылки и относительные пути, не копируем файлы. Плеер HTML5 для MP4/WebM, разрешённые iframe для YouTube/RuTube. Автовоспроизведение и loop отсутствуют. Структура позволяет изменить место блока на публичной странице позже.

## Миграция и безопасность

`0.5.15.sql`: новая таблица multi и только две новые колонки: `attribute_values.sample_image`, `product_videos.poster`. Старые product ID, SKU, цены, остатки, category assignments, галереи и URL остаются. Удаление использованного справочного значения запрещено. SQL выполнять штатным обновлением Joomla **после резервной копии БД**; не удалять и не переустанавливать компонент с нуля.

## Joomla browser smoke — выполнить после CI PASS и установки ZIP

1. Создать «Материал» → Текст → Готовые значения → Несколько. Добавить Металл и Камень с необязательными изображениями. Назначить категорию. В товаре выбрать оба и сохранить.
2. Открыть товар повторно: оба значения должны быть отмечены; затем снять один, сохранить и проверить. Попытка Multi → Single при двух значениях должна быть отклонена.
3. Попробовать создать «Цвет» с HEX и картинкой фактуры, назначить категорию; проверить редактирование существующих справочных значений без смены ID.
4. Создать тип «Файл» и выбрать документ через Joomla Media. HTML Editor / Number / Boolean проверить рядом.
5. В товаре вкладка Видео: добавить файл MP4 из Joomla Media, прямую HTTPS MP4 и ссылку YouTube; выбрать обложку. Сохранить, открыть повторно, поменять порядок, проверить публичное отображение без autoplay.
6. Проверить стандартный RU/EN UI и отсутствие потерь у ранее созданных товаров, фотографий, SKU, цены, остатков и URL. Отдельно тест legacy List и старых текстовых presets.

GitHub CI/ZIP, ручная Joomla приёмка и полный публичный фильтр — разные статусы. Не отмечать browser smoke PASS без выполнения.
