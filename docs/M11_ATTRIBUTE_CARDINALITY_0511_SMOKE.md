# MiniMarket 0.5.11 — одно или несколько значений List

**02.11.2026. Source + CI PASS (PHP 8.4/8.5, MySQL 8, Windows ZIP); реальная Joomla NOT RUN.**

В 0.5.10 количество выбираемых значений списка было ошибочно связано с флагом `is_variant`. В 0.5.11 в редактор **Attributes → Цвет** добавлено отдельное поле **Value selection / Выбор значений** при типе **List**:

- **One value / Одно значение:** у товара обычный выпадающий список; разрешено максимум одно значение.
- **Multiple values / Несколько значений:** у товара чекбоксы, можно выбрать несколько значений. **Не зависит** от «Distinguishes product variants / Различает варианты товара».
- Флаг **is_variant** отдельно обозначает, какие значения будут участвовать в будущих **реальных SKU-вариантах**. Настоящие комбинации, цены и остатки по SKU ещё не реализованы. Даже при одиночном выборе значения вариантный признак может быть включён.
- Для типов Text, Number, Yes/No поле выбора скрыто, `is_multiple=0`.
- При смене **Multiple → One** сервер проверяет наличие товаров, где сохранено 2+ значений данного свойства. Если есть — не разрешает переключение до изменения самих товаров. **Ничего не удаляется молча.**
- Миграция **0.5.11.sql** добавляет только поле `is_multiple` в `#__minimarket_attributes`. **Для существующих списков с is_variant=1 копирует 1**, чтобы прежний мультивыбор цветов/размеров остался прежним. Все товары, существующие связи с value_id, кодовые словари, фото, SKU, цена, остаток, ID, URL остаются неизменными.
- При создании **новой** характеристики List по умолчанию выбран режим **One value**, независимо от is_variant. Чтобы выбирать несколько, включить **Multiple values** вручную.
- Работают оба языка административной панели Joomla — ru-RU и en-GB. Нет изменений ядра Joomla.

## Установка

**Перед обновлением сделать резервную копию БД Joomla.** Нельзя удалять текущий MiniMarket и вручную выполнять SQL.

В CMD:

```bat
cd /d C:\OSPanel\home\minimarket.local
git pull --ff-only origin development
"C:\OSPanel\modules\PHP-8.5\php.exe" scripts\test-product-attributes.php
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\inspect-package.ps1
```

Ожидаемый результат: `PACKAGE_OK: 0.5.11 (com_minimarket-0.5.11.zip)`. Через Joomla → System → Install → Extensions установить `dist\com_minimarket-0.5.11.zip` **поверх** предыдущей версии.

## Короткая проверка

1. Открыть MiniMarket → Attributes → **Цвет**. При типе List должно появиться **Value selection**, с One value / Multiple values. Для уже существующего Цвета с вариантом Yes должно стоять **Multiple values** (унаследовано от старого поведения).
2. У старого тестового товара проверить, что сохранены красный/жёлтый, затем снова открыть саму характеристику. **Ничего не перезаписывать**, если данные верны.
3. Создать отдельную тестовую характеристику **Совместимые устройства** / `compatible_devices`, List, `Distinguishes variants=No`, `Value selection=Multiple values`. Добавить в ней несколько строк + и привязать её к тестовой категории. У товара должны быть чекбоксы, можно выбрать 2+ значения, сохранить и переоткрыть.
4. Создать тестовую характеристику List с `Distinguishes variants=Yes`, но **One value**. У товара должен быть один выпадающий список.
5. Попробовать переключить «Совместимые устройства» в One value при сохранённых двух значениях у товара: сохранение должно быть отклонено. Удалить лишний выбор из тестового товара, затем переключение разрешено.
6. Проверить, что у прежнего товара TEST-001 URL, ID, SKU, цена, остаток, галерея и публикация прежние. RU/EN переводы согласно языку Joomla.

**Граница:** новая настройка управляет только числом значений в редакторе товара; не создаёт реальных SKU-комбинаций и не включает публичные фильтры.
