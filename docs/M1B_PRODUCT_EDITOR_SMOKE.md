## Подготовка и обновление

1. Убедиться, что компонент версии `0.2.0` и тестовая категория на сайте работают (пользователь ответил «Готово»). При желании сделать свежий приватный экспорт базы `minimarket` в phpMyAdmin. Не прикреплять базу к чату/GitHub.
2. Открыть **PowerShell** в `C:\OSPanel\home\minimarket.local`. Проверить `git status --short`; при неожиданных изменениях не выполнять автоматическое очищение.
3. Получить и собрать:
```powershell
Set-Location 'C:\OSPanel\home\minimarket.local'
git pull --ff-only origin development
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```
4. Joomla admin → **Система → Установка → Расширения → Загрузка файла пакета** → выбрать локальный `C:\OSPanel\home\minimarket.local\dist\com_minimarket.zip`. Это **обновление** текущего компонента, **не удалять перед установкой**.

## Ручной smoke-test M1b — выполнить на одной тестовой записи

1. `Компоненты → MiniMarket → Товары` → **Создать**.
2. Заполнить: Название `Тестовый товар`; Категория `Тестовая категория`; SKU `TEST-001`; Цена `1990.50`; Остаток `3`; Статус `Опубликовано`. Псевдоним оставить пустым. Нажать **Сохранить и закрыть**.
3. Ожидается: в списке товаров строка с названием, артикулом, ценой `1990.50`, остатком `3`, категорией и статусом.
4. Повторно открыть товар по названию. Изменить остаток `3 → 2` и сохранить. Проверить, что значение обновилось, ID остался тем же, товар не дублировался.
5. Попробовать **отрицательную цену** (например `-1`) и неверный SKU (пустой) — сохранение должно отклоняться. После проверки вернуть исходные допустимые значения. Не применять эти тесты к реальным товарам.
6. Проверить `Категории` и главную страницу Joomla: прежняя категория не потеряна, сайт работает. **Публичная карточка товара пока не предусмотрена** — это следующий этап.
