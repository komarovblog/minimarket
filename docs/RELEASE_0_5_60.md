# MiniMarket 0.5.60 — ревью кода, поправки промовидео и проверка SKU

Дата: 2026-11-06. Ветка `development`; Joomla core и `main` не изменялись.

- Отчёт по подсистемам и открытым вопросам: [COMPONENT_REVIEW_0_5_60.md](COMPONENT_REVIEW_0_5_60.md).
- В промовидео можно развернуть ролик кликом на само видео, кнопкой или клавишами Enter/Space; aria-expanded синхронизируется, reduced-motion и закрытие работают как прежде.
- Формат метки скидки/выгоды на старых объектах без новых свойств безопасно использует percent/money и не выдаёт PHP warning.
- Проверка MySQL 8.4 сопоставляет реальные опубликованные SKU из демонстрационного SQL с товарными осями и значениями опций; больше недостаточно лишь `COUNT` вариантов.
- Дополнен статический регрессионный аудит глобальные настройки ↔ локальные ↔ БД ↔ витрина, promo/flags/JSON v2 wiring, DOM-тест клика/клавиатуры и обновлена документация.

С 0.5.59 уже имеются: режим процент/деньги для флагов, локальное промовидео (только MP4/WebM), расширенные медиа-строки в накопительном SQL и JSON v2 для 32 таблиц, с preview, rollback и проверкой конфликтов.

**Критические ограничения:** «Купить» в промо остаётся disabled — корзина/заказ не реализованы; JSON v2 **не включает сами файлы** изображений/видео; browser E2E на реальной Joomla пока не выполнен. Реальное сохранение и клики проверяются пользователем после установки ZIP.

## Порядок приёмки

1. Запустить `scripts/release-to-desktop.ps1` в локальном репозитории. На рабочем столе: `com_minimarket-0.5.60.zip` и `minimarket_mysql84_nnop3_update_0_5_60.sql`.
2. Сделать резервную копию БД, обновить компонент ZIP в Joomla и при необходимости импортировать накопительный SQL через phpMyAdmin.
3. Из отдельного **демо-медиа ZIP**, предоставленного в этой переписке, распаковать `images/minimarket` (без перезаписи собственных фото/видео). В нём 20 иллюстративных PNG и 3-секундный MP4; это тестовые материалы, не товарные фотографии.
4. В каталоге проверить товар `TOY-1012`: выбор комплектации/цвета, изменение SKU/фото/остатка, отключённое недоступное сочетание. Затем открыть галерею и промовидео (клик, Enter, Esc не назначен, закрытие крестиком). Проверить флаги скидка/выгода на товарах и комплектах.
5. Импорт/экспорт v2 проверять только в тестовой схеме или на резервной копии: для текущих отличающихся строк он откажется перезаписывать значения, как и должен.

## Автотесты

GitHub Actions: PHP 8.4/8.5; MySQL 8.0 схема обновления; MySQL 8.4 повторяемый демо SQL и JSON v2; Node DOM promo; Windows component package. Browser E2E `NOT RUN`. Установочные файлы Joomla проходят CI, но реальное поведение на OpenServer может отличаться.
