# MiniMarket 0.5.62 — кнопка быстрого перехода в шапке Joomla

Дата: 2026-11-06. Ветка: `development`. Joomla 6, PHP 8.4/8.5.

## Реализация

Отдельное расширение **administrator module** `mod_minimarket_quicklink`, встроенное в установочный компонент и дополнительно поставляемое отдельным ZIP:

- Название по умолчанию: **MiniMarket**.
- Иконка: `icon-cart` из штатной Joomla/Atum, текст MiniMarket.
- Ссылка: `administrator/index.php?option=com_minimarket&view=dashboard`; создаётся через Joomla Route и HTML-экранируется ровно один раз.
- Позиция по умолчанию `status` — в правой области верхней панели Atum на всех административных страницах.
- Модуль устанавливается **администраторским** (`client=administrator`), публикуется только при первой установке, заголовок не дублируется, доступ `Special`, назначение на все административные пункты (menuid=0).
- В шаблоне модуля класс `btn btn-sm btn-outline-primary` — стандартный Bootstrap, собственных CSS/JS, правок ядра и Atum нет.
- Доступ: перед выводом проверяется `core.manage` компонента, поэтому пользователи без полномочий магазина не видят кнопку даже при смене стандартного уровня доступа.

## Управление

Панель Joomla → **Материалы → Модули панели управления** / **Система → Модули панели управления** → фильтр по названию **MiniMarket**, открыть **MiniMarket — быстрый переход**.

Там можно:
- включать/выключать публикацию и внутреннюю настройку «Показывать кнопку»;
- менять текст (по умолчанию MiniMarket);
- независимо скрывать значок корзины и название;
- менять штатную позицию Joomla, например `status` (правый верхний угол), `customtop` (отдельная верхняя область);
- менять уровень доступа и порядок среди других модулей позиции.

Изменения параметров сохраняются в штатной таблице `#__modules`. **Обновление MiniMarket не переопубликовывает модуль и не возвращает вашу позицию**, поскольку параметры изменяются установочным скриптом только при первой установке типа модуля.

## Установка и восстановление

Обычный способ:
1. Установить `com_minimarket-0.5.62.zip` поверх MiniMarket. Его `script.php` вызывает Joomla `Installer` для вложенного модуля после установки собственных файлов.
2. При **первом** появлении `mod_minimarket_quicklink` Joomla создаёт штатную запись модуля, компонент конфигурирует её и связывает со всеми административными пунктами.
3. Если модуль ранее уже существовал, обновляется **только его код** — пользовательские настройки/публикация/назначения не меняются.
4. Если установка модуля не прошла, Joomla показывает предупреждение, но обновление MiniMarket продолжается. Для восстановления есть отдельный ZIP `mod_minimarket_quicklink-0.5.62.zip`, который можно установить стандартным способом «Система → Установить → Расширения»; затем в «Модулях панели управления» поставить `status`, опубликовать, выбрать уровень доступа `Special` и назначить на все страницы.

Никаких прямых миграций Joomla системных таблиц в SQL-файле нет: штатный Joomla `Installer` и API БД выполняют необходимые операции. **Не импортируйте демонстрационный SQL ради кнопки**.

## Комплект поставки

После:
```powershell
Set-Location 'C:\OSPanel\home\minimarket.local'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\release-to-desktop.ps1
```
рабочий стол:
- `com_minimarket-0.5.62.zip` — содержит компонент + исходники административного модуля;
- `mod_minimarket_quicklink-0.5.62.zip` — самостоятельная установка/восстановление модуля;
- `minimarket_mysql84_nnop3_update_0_5_62.sql` — накопительный тестовый каталог для ручного импорта, не имеет отношения к кнопке.

## Проверки

- `php scripts/test-0-5-62-quicklink.php` — XML-манифест, перевод RU/EN, HTML-кнопка, ссылка, `core.manage`, переключатели, экранирование и отсутствие пустой кнопки.
- `php scripts/test-0-5-62-installer.php` — изолированный mock Joomla Installer и БД, первая установка, сохранение пользовательских настроек при повторном обновлении, предупреждение с инструкцией при ошибке.
- PHP 8.4/8.5 и Windows: `scripts/build.ps1` и `inspect-package.ps1` проверяют оба ZIP и версию.
- MySQL 8.0/8.4 — обратная совместимость существующего каталога и накопительного SQL.
- **На настоящем Joomla 6/Atum после установки ещё не проверено**: фактическая регистрация модуля в расширениях, наличие публикации на позиции `status` и расположение кнопки на разных ширинах/темах. Это ручной приёмочный шаг; не отмечать browser E2E как PASS.

## Приёмка

Проверить после установки на локальном сайте: верхняя панель содержит кнопку с корзиной и «MiniMarket»; переход открывает `view=dashboard`; на всех разделах Joomla кнопка остаётся видимой; у пользователя без `core.manage` модуль не рендерится. Выключить кнопку в модулях и установить компонент повторно: она должна **остаться выключенной**. Вернуть публикацию и проверить текст/иконку/позицию.
