# MiniMarket 0.5.97 — настройки, товары, оформление заказа и отзывы

## Изменения
1. У системных атрибутов Цена/Артикул/Наличие удалены собственные тёмные рамки. Под общим синим информером — штатные Joomla spacer-названия и по два рабочих параметра.
2. Отображение переключается штатными списками «Показывать/Скрывать»; значения 1/0 сохранены для уже установленных настроек. Старый JS, оборачивавший группы настроек в дополнительную card, отключён.
3. Управление количеством товаров и переключением страниц перенесено в Основные → Пагинация. Стандартные SEO-страницы и новая подгрузка порциями используют серверный расчёт, сортировку и фильтры одной витрины. Поддерживаются кнопки следующие/предыдущие N и автоматическое дополнение вниз/вверх при прокрутке; при ошибках AJAX ссылка открывается обычным GET.
4. У всех шести Bootstrap-сеток единые подписи, единые подсказки диапазона/контейнера/класса; дублирование заголовка продуктовой группы удалено.
5. Глобальное отображение характеристик/опций разъясняет, что показываются только разрешённые в привязке к категории.
6. Checkout: кнопка входа; описание каждого шага, безопасный пропуск шагов, пользовательские поля (максимум 20: текст, телефон, email, число, textarea, список, checkbox); поле маски телефона и маска дополнительных текстовых полей. Проверки выполняются на сервере, снимки дополнительных значений сохраняются в `#__minimarket_order_custom_values` в транзакции создания заказа. Пропуск покупателя разрешён только вошедшему пользователю с email и без обязательных пользовательских полей; пропуск доставки автоматически выбирает самовывоз, если он доступен; пропуск оплаты автоматически выбирает первый доступный метод. Нельзя обходить существующие правила.
7. Отзывы: все / зарегистрированные; модерация всех, только гостей или никого. Храним 1/0/2, чтобы сохранённый прежний 0 продолжал означать модерацию гостей.

## Схема и установка
Аддитивная миграция `admin/sql/updates/mysql/0.5.97.sql` создаёт отдельную таблицу, имеющиеся заказы не изменяются. SQL демоданных на рабочей БД запускать не нужно. Сборка: `scripts/release-to-desktop.ps1 -SkipPull`; поставка component ZIP, отдельного toolbar ZIP и необязательного cumulative SQL. Joomla 6, PHP 8.4/8.5, MySQL 8.4.

## Приёмка
Автотест: `php scripts/test-0-5-97.php`, PHP lint и JS syntax, CI MySQL fresh/upgrade и Windows ZIP. Важно отдельно проверить в установленной Joomla RU/EN, тёмную и светлую темы, доступность редактора дополнительных полей в com_config, JavaScript маски, оплату самовывоза, Ajax-подгрузку вверх/вниз, review moderation и сохранение нового заказа. Без этого браузерную приёмку не объявлять завершённой.

**Не меняли:** Joomla core, репозиторий Blank, `main`, старые SKU, изображения товаров, интеграции CDEK/SMS/online payments. Внешние провайдеры по-прежнему требуют реальные плагины.
