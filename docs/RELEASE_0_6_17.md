# MiniMarket 0.6.17 — зеркальная совместимость и реальные точки самовывоза

## Что реализовано

1. **Способы доставки → Самовывоз/Курьер → Совместимость.** Обратная редактируемая вкладка: отмеченные способы оплаты записываются в **те же** параметры `payment_*_allowed_deliveries`, что и у способов оплаты. Нет второй матрицы. Сохранение атомарное с блокировкой `#__extensions`, проверкой CSRF и `core.options/core.admin`. Неактивная оплата отмечена как неактивная, но её сохранённая совместимость не теряется.
2. **Способы доставки → Самовывоз → Точки.** Реальные места с названием, адресом, графиком, HTTPS-картой, собственной ценой, публикацией. Нативные вкладки Joomla/таблица. Исторический режим одного адреса остался по умолчанию.
3. **Самовывоз → Основное → Режим:** «Один адрес» / «Несколько точек». При втором режиме показываются только реально опубликованные точки; в форме оформления и ручного заказа покупатель/сотрудник выбирает нужную. Сервер получает `pickup_point_id`, независимо перечитывает адрес и плату по сохранённой записи и заносит **снимок адреса и ID** в заказ. Смена адреса пункта позднее не меняет старый заказ. При отсутствии активных точек оформление не разрешается.
4. Условия видимости и HTML-классы берутся из Bootstrap/Joomla, без самодельного оформления. RU/EN переводы.
5. **Не создавались** новые движения склада, отдельный плагин самовывоза, API перевозчиков, платежи или фискальные чеки.

## Миграция и проверка

`0.6.17.sql` — только новая таблица `#__minimarket_pickup_points` и nullable `#__minimarket_orders.pickup_point_id`. Без переписывания старых заказов. При удалении пункта историю заказа сохранять; пока применяются публикация/снятие с публикации.

Адресные тесты: `test-0-6-17-pickup-mirror.php` и `test-0-6-17-migration-mysql84.php`. Плюс полный CI PHP 8.4/8.5, MySQL 8.4 и Windows ZIP. Браузерная проверка Joomla 6 после установки обязательна и отдельно фиксируется.

Выпуск: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\OSPanel\home\minimarket.local\scripts\release-to-desktop.ps1"`. ZIP: `com_minimarket-0.6.17.zip`; не импортировать демонстрационный SQL вручную.
