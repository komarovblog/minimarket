## Как читать план

- **[x]** — подтверждено пользователем в работающей Joomla (или для автоматических проверок явно указано CI PASS).
- **[~]** — часть кода реализована, либо проверена лишь частично, но весь шаг ещё нельзя считать готовым.
- **[ ]** — не выполнено. Подготовленная документация ≠ работающий функционал.
- **[?]** — требует проектного решения, прежде чем писать код.
- **Номер шага не равен версии ZIP.** Версии 0.3.11 и 0.4.0 — номера сборок; шаги вида 1.2.3 — порядок разработки и критерии приёмки.
- Закрывать шаг можно только после проверки **админки + публичной страницы + сохранности данных + маршрутов/SEO, когда они затронуты**. Автотесты GitHub не заменяют проверку установленной Joomla.
- Новая задача не становится текущей только потому, что по ней уже есть код. Предыдущие зависимости должны быть закрыты или осознанно отложены с указанием причины.
