## Как читать план

- **[x]** — подтверждено пользователем в работающей Joomla (или для автоматических проверок явно указано CI PASS).
- **[~]** — часть кода реализована, либо проверена лишь частично, но весь шаг ещё нельзя считать готовым.
- **[ ]** — не выполнено. Подготовленная документация ≠ работающий функционал.
- **[?]** — требует проектного решения, прежде чем писать код.
- **Номер шага не равен версии ZIP.** Версии 0.3.11 и 0.4.0 — номера сборок; шаги вида 1.2.3 — порядок разработки и критерии приёмки.
- Закрывать шаг можно только после проверки **админки + публичной страницы + сохранности данных + маршрутов/SEO, когда они затронуты**. Автотесты GitHub не заменяют проверку установленной Joomla.
- Новая задача не становится текущей только потому, что по ней уже есть код. Предыдущие зависимости должны быть закрыты или осознанно отложены с указанием причины.

### Реализация 1.2 — 01.11.2026, исходники CI PASS / Joomla NOT RUN

- Используется **существующий** `#__minimarket_categories.parent_id` без SQL-миграции, изменения идентификаторов и изменения плоских маршрутов.
- В редакторе Joomla добавлен выбор родительской категории, в админском списке показывается название родителя. Сохранение запрещает назначение себя, любого своего потомка, отсутствующего родителя и циклы, сохраняет выбранный `parent_id`.
- На главной витрины выводятся только верхнеуровневые опубликованные категории; на странице категории — прямые опубликованные дочерние. Маршрут дочерней остаётся `/category/alias-id`. Товар остаётся в своей непосредственной категории.
- Неопубликованная/осиротевшая/циклическая ветка не видна в публичном каталоге: проверка учитывает всех предков, в том числе на прямых URL товара и категории и в общей выдаче товаров.
- Проверки `scripts/test-category-tree.php` и обновлённый `scripts/test-catalog.php` включены в CI. **Нужно проверить фактическое сохранение формы и ссылки в Joomla**. Порядок сортировки, ручное дерево в админке, изображения и метаполя относятся к 1.3–1.6 и 3/5; этот этап пока [~], не [x].
- Опережающие исходники атрибутов 0.4.0 всё ещё находятся в этой ветке: **не устанавливать текущий ZIP на рабочую Joomla без отдельной проверки миграции/выпуска**. Исторический smoke атрибутов не является актуальной задачей.
