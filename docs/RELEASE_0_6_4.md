# MiniMarket 0.6.4 — редакторы, категории, опции и одноразовый toolbar

**Ветка:** `development`, база 0.6.3. **Среда:** Joomla 6, PHP 8.4/8.5, MySQL 8.4. Не менять ядро Joomla и проект Blank. Локальная браузерная приёмка обязательна отдельно от CI.

## Изменения

1. Подкатегории: в глобальных настройках → Отображение и в отдельной категории доступен счётчик карточек по XS/SM/MD/LG/XL/XXL. Локальные `subcategory_cards_*` наследуются из глобальных через `-1`, независимо от режима отображения товаров. Витрина рендерит подкатегории в Bootstrap `row-cols-*` и карточках ссылок. **Миграция** `admin/sql/updates/mysql/0.6.4.sql` добавляет шесть полей в категории; старые записи наследуют глобальные значения.
2. Характеристики и опции: `filter_multiple` и `filter_search` вместо радио на native Joomla select «Не показывать / Показать»; для опций появилась вкладка «Фильтр» с типом, множественностью, поиском. Данные теперь сохраняются в `#__minimarket_order_options`, а `FacetedCatalog` читает их при формировании SKU-фасетов. Для старых опций default `checkboxes, multiple=1, search=0` сохраняет поведение.
3. Значения характеристики и опции: действующие Joomla repeatable-поля группируются в родной `details/summary`, сворачиваются по умолчанию для существующих значений; заголовок и код видны в компактной строке. Новые значения развёрнуты для ввода. Сохранение и сортировка ID/полей не меняются. Файл значения показывается только для типа информационной характеристики `document` («Файл»), для остальных типов скрыт. У SKU-опции нет типа «Файл» — хранилище и складской контракт опций не расширяются в рамках UI-итерации.
4. Первая вкладка `Основное` унифицирована у категорий, характеристик, опций, товаров и комплектов, брендов, коллекций, связей, значений, SEO, промокодов, зон доставки и фидов. Форма без вкладок остаётся без искусственно добавленных вкладок.
5. Исправлены отсутствующие импорты `Service\\CategoryListVisibility` у полей `CategoryattributesField` и `CategoryorderoptionsField` — причина падения страницы категории. Убрана колонка «В ветке» из списка категорий; внутренний подсчёт не изменён.
6. Общий picker одиночных сущностей после выбора показывает «Сменить», рядом доступны «Редактировать» (когда передан адрес сущности) и «Удалить». У отзыва выбранный товар открывается в своём редакторе; поиск и смена привязки сохраняются.
7. Версия компонента выводится рядом с заголовком основной панели управления из установленного manifest_cache Joomla; в верхней кнопке версия не дублируется.
8. Исправлена локализация native Joomla preset `COM_MINIMARKET_MENUS_PRESET_MINIMARKET` (RU/EN). Сам `mod_minimarket_toolbar` версии **0.6.3** — уже независимый модуль Joomla. Его достаточно установить **один раз**, далее он открывает актуальный компонент. Новый ZIP модуля при выпуске компонента больше не генерируется и на Desktop не копируется. В обычном релизе — компонент ZIP и отдельный необязательный накопительный demo SQL.

## Проверка до релиза

Тест `scripts/test-0-6-4-ui.php` проверяет консистентность категорий, миграции, фасеты, вкладки, импорт зависимостей, единые пикеры, локализации и разделение module/component. Старые tests PHP/JS/MySQL должны остаться зелёными. Сверить PHP 8.4/8.5, MySQL 8.4, Windows ZIP. Проверить Joomla с реальной БД: создание и открытие категории; сохранение двух вариантов сетки для XS/XXL; публикация опции и выбор фильтра; SKU-совместимость; старые значения; RU/EN, светлая/тёмная темы, добавление/смена/удаление продукта в отзыве.

**Бэкап БД перед обновлением обязателен:** миграция 0.6.4 меняет схему двух таблиц. При откате к 0.6.3 старые поля и данные сохраняются, но для точного восстановления рекомендуется восстановить БД из бэкапа.

## Единственная команда для выпуска ZIP на рабочий стол

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\OSPanel\home\minimarket.local\scripts\release-to-desktop.ps1"
```
